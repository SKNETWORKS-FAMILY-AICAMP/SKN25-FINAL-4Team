EMS Evaluation QA Dataset
=========================

파일명
------
ems_eval_evidence_97.json

목적
----
본 데이터셋은 EMS(Energy Management System) Agent 및 sLLM 모델의
Evidence Answer 성능 평가를 위한 평가용(Evaluation) QA 데이터셋이다.

학습용 데이터(Expert QA, Chat QA)와 별도로 사용되며,
정답(reference_answer)이 명확하게 존재하는 질의만 포함한다.

평가 대상
--------
- LangGraph Evidence Answer 경로
- RAG + DB 조회 기반 응답
- sLLM Fine-tuning 모델
- EMS Agent 응답 정확도

구성
----
총 97개 QA

- Anomaly QA : 40개
- CMS QA     : 27개
- Report QA  : 30개

모든 QA는 evidence_answer 유형으로 구성된다.

데이터 구조
-----------
각 항목은 다음 필드를 가진다.

id
    평가 문항 고유 ID

query
    사용자 질문

category
    anomaly / cms / report

eval_type
    평가 유형
    현재는 evidence_answer만 사용

difficulty
    easy / medium / hard

source_doc
    정답 생성에 사용된 원본 데이터

answer_chunks
    정답 생성에 필요한 근거 정보

reference_context
    정답 생성 시 사용된 원본 컨텍스트

reference_answer
    평가 기준 정답

카테고리 설명
------------

1. Anomaly QA (40)

이상탐지 결과 기반 평가

예시:
- 2023-11-01부터 2023-11-30까지 PowerSpike 이상 후보는 몇 건 발생했나요?
- 2023-05-01부터 2023-05-31까지 CHPOutage 이상 후보는 몇 건 발생했나요?

평가 항목:
- 기간 인식
- 이상 유형 인식
- 건수 조회
- 등급(HIGH/MEDIUM/LOW) 조회
- 근거 기반 응답 생성

사용 테이블:
- anomaly_results


2. CMS QA (27)

작업지시 및 설비 상태 기반 평가

예시:
- CHP 설비의 헬스 스코어는 얼마인가요?
- 태양광 설비의 최근 이상 건수는 몇 건인가요?
- 현재 점검 우선순위가 높은 설비는 무엇인가요?

평가 항목:
- 설비 식별
- 헬스 스코어 조회
- 최근 이상 건수 조회
- 작업지시 상태 조회
- 점검 우선순위 판단

사용 테이블:
- work_orders


3. Report QA (30)

월별 KPI 및 운영 현황 기반 평가

구성:
- 단일 KPI 조회형
- 복합 KPI 요약형
- 전월 비교형

예시:
- 2023년 5월 자급률은 얼마인가요?
- 2023년 7월 전력 사용량과 자급률을 요약해주세요.
- 2023년 8월 자급률은 전월 대비 얼마나 변했나요?

평가 항목:
- KPI 조회
- 수치 요약
- 월별 비교
- 보고서 정보 활용

사용 테이블:
- monthly_energy_summary
- report_mart


평가 원칙
---------
1. 정답(reference_answer)은 고정값이다.

2. 평가 시 의미적으로 동일한 답변은 정답으로 인정할 수 있다.

3. 수치 정보는 reference_answer와 일치해야 한다.

4. hallucination(근거 없는 정보 생성)은 오답으로 처리한다.

5. answer_chunks와 reference_context에 존재하지 않는 정보는
   정답으로 인정하지 않는다.

활용 방법
---------
1. Expert QA + Chat QA
   → sLLM 학습(Fine-tuning)

2. ems_eval_evidence_97.json
   → 학습 완료 모델 평가

3. 평가 지표
   - Exact Match
   - Semantic Similarity
   - Groundedness
   - Evidence Consistency

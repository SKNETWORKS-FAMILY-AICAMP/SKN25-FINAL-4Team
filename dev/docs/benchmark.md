# K-FEMS 벤치마킹 분석

> ETRI 주관 K-FEMS 표준 플랫폼([portal.kfems.kr](https://portal.kfems.kr)) 브로셔 전체 분석.
> EMS Agent가 차용할 기능과 차별화할 영역을 명확히 구분한다.

> ⚠️ **최신 반영 (2026-06 — CMS 전환 이후):**
> 이 문서는 **에너지 관리(FEMS)** 시절 K-FEMS 벤치마킹이다. 이후 프로젝트는 **CMS(설비 상태감시·예지보전)** 로 피벗했다.
> - **주 경쟁군 변경**: K-FEMS(에너지) → **Pi-CMS(진동 예지보전)·WP솔루션즈(설비 이상탐지)** (둘 다 물리센서 전제). 우리 니치 = 센서 증설 없이 전기·에너지 데이터 + LLM 코파일럿. 상세는 메모리 `ref_cms_competitors`.
> - **아래 "우리 현황/권고"는 FEMS 시절 기준** — 일부는 이미 CMS로 구현됨: 설비 이상진단(Φ_act=Φ_fit) → ✅ AI 진단(전기 시그니처) / 설비 상태·정비 → ✅ CMS 4대 축 / Tracking 추세 → ✅ 월간 YoY·MoM / 외기온 정규화 EI → ✅ `/report/energy-intensity`.
> - K-FEMS의 **기능 카탈로그·수식(η/EI/E_BL)** 분석은 도메인 참고자료로 여전히 유효해 원문 보존.

## 1. K-FEMS 전체 구조 (9페이지 정리)

### 1.1 시장 배경 (p.2)
- 한국 산업부문 에너지 사용량 **63.1%** — 제조업 비중 압도적
- 선진국 대비 산업부문 에너지 사용량: 한국 52% (일본 37%, 영국 31%, 미국 20%)
- 11만 제조기업 중 **97%가 중소기업** — FEMS 도입 비용·운영·관리자 부담이 가장 큰 장벽
- 2030 온실가스 40% 감축 / 2050 탄소중립 정책 압박

### 1.2 산학연 컨소시엄 (p.3)
- **수행기관:** ETRI (총괄)
- **App 개발:** LSITC, 나노스정보, 티스마트
- **Data 처리:** 에스디플렉스, 누리플렉스, 한국전자기술연구원
- **운영 환경:** SQI소프트, 이노그리드, 중앙대학교
- **사업화:** 한국에너지공단, 한국산업단지공단
- **표준화·생태계:** 한국EMS협회
- **수요기업:** 현대두산인프라코어
- **IPR:** 특허 118건, SCIE 논문 55편 이상, ITU-T 등 표준 기고 40여건

### 1.3 기술 제품 3종 (p.4)

| 제품 | 구성 |
|------|------|
| **Smart FEMS (On-Premise)** | Application Module + FEMS Framework (Baseline Modeler / Object Modeler / Time-Series DB) + DAS (Data Acquisition System) |
| **Optimizer** | Analytics (수급관리, 공정/설비진단) + Controller (Smart Utility Energy, Smart Process Energy) |
| **Cloud FEMS Service** | Customer Service + FEMS Service + Edge Computing |

**사업 구조:** FOC (Operation Center) ↔ FMP (Market Place) ↔ FDP (Distribution Portal)
- Partner / 3rd Party / Customer 3자 협업 모델
- 핵심 가치: 비용 부담 해소 / 투명한 가격 결정 구조 / All Life 서비스 구조

### 1.5 표준 플랫폼 핵심 모듈 (p.5)

**최적화 모듈 (수식 명시):**
| 모듈 | 수식 | 의미 |
|------|------|------|
| 유틸리티 효율분석 | **η = E_meas / E_BL** | 측정값 / 베이스라인 비율 |
| 공정 원단위 분석 | **EI = E_BL / P** | 베이스라인 / 생산량 |
| 에너지 Balancing | **E_BL = Σ E_i** | 부문별 합산 = 메인 미터 |

| 공정 최적화 운전 | **P_opt = ∂E_BL/∂P = 0** | 한계 에너지 0인 생산점 |
| 에너지 밸런스 시각화 | — | 대시보드 |

## 3. 벤치마킹 가치 평가

**5단계 등급 — A(즉시 도입) / B(중기 도입) / C(장기 검토) / D(차용 불가) / E(차별점이라 의도적으로 안 함)**

### A. 즉시 도입 가치 — 데모 임팩트 직결

1. **Energy Facade의 Tracking 추세관리** — 일정 기간 누적 비교
   - 현재 월간 보고서가 있지만 **전년동월 / 전월 자동 비교 narrative**가 약함
   - 구현: 기존 `/report` 응답에 비교 텍스트 추가 (1~2시간)

2. **Energy Lens의 에너지 밸런스 검증** — E_BL = Σ E_i
   - 부문 합산이 메인 미터와 일치하는지 자동 검증 → 미터 데이터 품질 이슈 자동 탐지
   - **새로운 인사이트 가치**: 데이터 신뢰도가 보고서에 자동 반영됨
   - 구현: 미터 토폴로지 기반 합산 검증 함수 (3~4시간)

3. **K-FEMS의 7개 모듈 수식을 도메인 지식에 명시**
   - 이미 `KFEMS_STANDARD_TERMS`에 일부 포함했지만, 수식 자체를 LLM이 알면 자연어 답변의 깊이가 달라짐
   - 구현: 도메인 지식 보강 + 채팅 답변에 수식 인용 권장 (30분)

### B. 중기 도입 가치 — Phase 2

4. **Energy Lens의 실시간 원단위 (EI = E_BL/P)**
   - Honda 데이터에 생산량(P) 없음 → **운영시간 또는 외기온 정규화로 proxy**
   - 예: "외기온 정규화 원단위" = 전력 소비 / 외기온 (난방·냉방 모드 분기)
   - 구현: 데이터 column 추가 + 새 KPI 카드 (4~6시간)

5. **사업장 에너지랭킹 (Energy Guardian)** — 자기 자신과의 비교
   - 멀티 사이트 비교는 불가능하지만 **시계열 자기비교**로 변형
   - "이번 달 동일 미터 vs 전년 동월" 랭킹 → 어떤 부문이 가장 악화/개선됐는지
   - 구현: 미터별 변화율 랭킹 컴포넌트 (3~4시간)

6. **공정 원단위 분석 표 (p.5의 5가지 보급 모델)**
   - 우리 데모를 "고급형~전문형 Tier 서비스"로 포지셔닝 → 시장 적합성 설명력 향상
   - 구현: VISION.md 갱신 (이미 일부 포함)

### C. 장기 검토 — 사업화 단계

7. **시장/타시스템 연계 (DR/RE100/VPP/ESG/ETS)**
   - 한국 한전 DR API 또는 RE100 트래킹 통합
   - **우리 데이터는 독일 시설이라 직접 연계 불가** → 향후 한국 시설 적용 시 필수
   - 영향: 가장 큰 사업 확장 카드지만 데모에는 부담

8. **OneM2M / OPC-DA Edge Gateway 어댑터**
   - 실배포 시 표준 프로토콜 지원
   - 데모는 PostgreSQL 직접 → 표준 인터페이스 어댑터는 사업화 단계

### D. 차용 불가 — 비즈니스 모델이 다름

9. **Energy Fairground (FMP, 마켓플레이스)**
   - K-FEMS는 정부 주도 표준 플랫폼 → 다양한 벤더 거래 모델
   - 우리는 단일 서비스 → **의도적으로 안 함**

10. **컨소시엄·산학연 추진 체계**
    - 정부 과제 구조 — SK Networks 4팀 프로젝트와 무관

### E. 의도적 차별화 — 차용하면 오히려 손해

11. **5단계 모델·정교한 가격 정책 (계측기 수량 기반)**
    - K-FEMS는 도입 비용 부담 해소가 핵심 가치
    - 우리는 **AI 코파일럿** 가치 — 모델 수가 아니라 의사결정 품질
    - 차용하면 우리 차별화 메시지가 희석됨

12. **8개 업종 실증사이트**
    - 우리는 Honda R&D 단일 데이터셋 — 일반화보다 **깊이로 차별화**
    - "한 사이트를 누구보다 잘 분석하는 AI"가 우리 메시지

## 4. 최종 권고: 우선순위 3가지

K-FEMS 자산 중 **데모 임팩트 대비 구현 비용이 낮은 3개**만 즉시 차용:

### 🥇 1순위: 에너지 밸런스 검증 (Energy Lens 차용)
- **무엇:** 메인 미터(V.Z81+V.Z82) = 부문 합산 자동 검증 → 차이 5% 이상이면 데이터 품질 경고
- **왜:** AI가 "이 보고서는 신뢰할 수 있다"고 보증하는 효과. **K-FEMS는 표로만 보여주지만 우리는 AI가 직접 해석**
- **시간:** 3~4시간
- **데모 가치:** ⭐⭐⭐⭐⭐

### 🥈 2순위: Tracking 추세 비교 (Energy Facade 차용)
- **무엇:** 월간 보고서에 **전년동월·전월 자동 비교 narrative** 추가
- **왜:** 현재 보고서가 "이번 달 X kWh" 수치만 → "전년 동월 대비 12% 증가, 주 원인은 7월 외기온 상승"으로 격상
- **시간:** 2~3시간
- **데모 가치:** ⭐⭐⭐⭐

### 🥉 3순위: 외기온 정규화 원단위 (Energy Lens 변형)
- **무엇:** 생산량 없는 대신 **외기온 정규화 EI** = 전력 / (외기온 - 18°C)

## 5. 결론

**K-FEMS는 시장 카탈로그, 우리는 카탈로그 위의 AI 코파일럿이다.**

K-FEMS의 기능 카탈로그는 그 자체로 우리 서비스의 **로드맵 지도** 역할을 한다.
- 그들이 표·차트·수식으로 보여주는 것을 → 우리는 **자연어와 권고문**으로 압축한다
- 그들이 7가지 모듈로 나눈 것을 → 우리는 **하나의 채팅창**으로 통합한다

**도입할 것 3개 (위 권고)**, **차별화로 유지할 것 2개 (자연어 + AI 브리핑)**, **의도적으로 안 할 것 명확히 하기 (마켓플레이스·멀티사이트)** — 이게 벤치마킹의 결론이다.

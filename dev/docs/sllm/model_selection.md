# sLLM 모델 선정 및 성능 최적화 — Gemma4 12B + EXAONE 3.5 7.8B 듀얼 아키텍처

> **결론**: 듀얼 모델 아키텍처 채택. (최종 업데이트: 2026-06-11)  
> **Gemma4 12B** — 품질 경로 (진단·보고서·분석): **8.5/10** (gpt-5.5 심사 기준, gpt-4o 8.1 상회)  
> **EXAONE 3.5 7.8B** — 속도 경로 (의도 분류): **10.0/10** (평균 2,540ms)  
> **심사위원**: 2026-06-11부로 GPT-4o → **GPT-5.5** 교체. 더 엄격한 근거성 평가 적용.  
> 현재는 RunPod 전용 GPU에서 PoC이며, 최종 목표는 사내 GPU 서버 배포.

## 3-3. 성능 향상을 위한 기술 스택

### Inference 최적화

| 기술 | 적용 파일 | 내용 | 효과 |
|---|---|---|---|
| `keep_alive: -1` | `llm_client.py` | 모델 영구 VRAM 상주 (idle 퇴출 없음) | 재로딩 지연 0ms |
| `OLLAMA_MAX_LOADED_MODELS=2` | RunPod 환경변수 | 두 모델 동시 VRAM 상주 | 모델 전환 지연 없음 |

| `temperature` 분리 | `llm_client.py` | fast=True: 0.1 / fast=False: 0.3 | 의도분류 결정론적, 진단 창의적 |
| `thinking` 파라미터 | `llm_client.py` | quality: ON, fast: OFF, RAG: 명시 OFF | 역할별 최적 추론 모드 |
| `num_predict = max_tokens × 4` | `llm_client.py` | thinking=True 시 토큰 버짓 확보 | 빈 응답 방지 |
| RAG thinking OFF | `rag_agent.py` | 도메인 설명은 thinking 불필요 | ~10s → ~3s |
| Ollama 네이티브 API | `llm_client.py`, `harness.py` | `/api/chat` 직접 호출 (OpenAI-compat 대신) | `think` 파라미터 제어 가능 |

## 4. GPT 대비 sLLM 선택 이유

최종 온프레미스 배포에서는 공장 에너지·설비 데이터를 외부 LLM 서비스로 전송하지 않는 구성을 목표로 한다. 현재 RunPod 단계는 모델 품질·VRAM·응답 시간을 검증하기 위한 외부 GPU PoC이므로 실제 온프레미스 운영과 구분한다.

Gemma4는 내부 평가셋에서 **9.2**, GPT-4o는 **9.1**을 기록해 유사한 품질 가능성을 확인했다. 0.1점 차이는 단일 평가 결과이므로 우열보다는 대등한 수준으로 해석한다.

## 5. Qwen2.5가 탈락한 이유

복잡한 수치 추론 과정에서 **한국어에서 중국어로 언어가 전환**되는 현상이 발생했습니다.

```
[예지보전 프롬프트 — Qwen2.5 실제 응답 중 발췌]
"... 2024년 4~5月间（April-May 2024）,
COP可能会达到1.5以下的临界值。建议..."
```

공장 운영자가 읽어야 하는 진단 보고서에서 언어 전환은 실사용 불가 수준의 결함입니다.

## 6. 프롬프트 엔지니어링 적용 현황

아래 최적화가 현재 발표용 PoC에 적용되어 있습니다. Gemma4는 thinking 능력 덕에 few-shot 없이도 좋은 결과를 내지만, 형식·도메인 지식 보강은 모든 모델에 유효합니다.

| 적용 위치 | 내용 |
|---|---|
| `cms.py` | 설비 유형별 few-shot (소비/발전 설비 분기) |
| `cms.py` | HIGH/MEDIUM/LOW 심각도 레이블 명확화 |
| `reporting_agent.py` | 섹션별 출력 + 할루시네이션 방지 지시 |
| `report.py` | 일일 브리핑 few-shot (SUMMARY/ACTIONS 형식) |

## 8. 결론

**Gemma4 12B**을 최종 채택합니다.

1. **GPT-4o와 대등한 내부 평가 결과** — 33문항에서 Gemma4 9.2/10, GPT-4o 9.1/10.

3. **한국어·형식 안정성** — 형식 9.3, 논리성 9.4. 보고서·진단 출력 품질 최고.

6. **스트리밍 UX** — 프론트엔드 SSE 스트리밍으로 단계 메시지 표시, 체감 대기 단축.

# eda/sliding/

슬라이딩 윈도우 시각화. 연도 간 비교, drill-down, 일별 패턴 분석.

| 파일 | 내용 |
|---|---|
| `eda_sliding_electric.py` | 전기 계량기 슬라이딩 윈도우 static PNG 생성 |
| `eda_sliding_heat.py` | 열량계 슬라이딩 윈도우 static PNG 생성 |
| `eda_plotly_sliding_dashboard_electric.py` | 전기 계량기 슬라이딩 Plotly 대시보드. cross-year, drill-down, weekday/week/month compare 포함 |
| `eda_plotly_sliding_dashboard_thermal.py` | 열량계 슬라이딩 Plotly 대시보드. 전기 대시보드의 `generate_dashboard`를 열량계용으로 재사용 |

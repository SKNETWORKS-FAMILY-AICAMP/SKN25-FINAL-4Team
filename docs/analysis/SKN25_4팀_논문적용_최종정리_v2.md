# SKN25기 4팀 논문 적용 최종 정리

## 1번 논문 — SSA-IPSO-LSTM 예측 모델 (Lai et al. 2025)

### 논문 개요
- **논문명**: Deep Learning-Based Energy Consumption Prediction Model for Green Industrial Parks
- **핵심 방법론**: SSA로 시계열 고주파/저주파 분해 → Fuzzy Entropy로 성분 분류 → IPSO로 LSTM 하이퍼파라미터 최적화 → 합산 예측
- **논문 데이터**: 744개(1개월), 단일 건물

### 저희 데이터 적용
- **데이터**: Honda R&D Europe 부지 전체, 35,064개(4년), 1시간 단위
- **분할**: train 2018~2021 / validation 2022 / test 2023
- **피처**: grid_P, pv_P, chp_P, Ta, Igm, 시간 피처(sin/cos) 10개

### 구현 과정에서 발생한 문제
- Fuzzy Entropy O(N²) 연산 문제 → 500개 샘플링으로 해결 (논문 744² → 저희 35,064²)
- IPSO 순차 연산이라 GPU 효율 없음 → CPU/GPU 구간 분리 필요
- IPSO 50 iteration × 10 particles → 10 iteration × 5 particles로 축소

### 실험 결과

| 항목 | 값 |
|---|---|
| 고주파 최적 파라미터 | units=32, batch=12 |
| 저주파 최적 파라미터 | units=128, batch=12 |
| MAE | 595,343 W |
| RMSE | 613,237 W |
| MAPE | 3,178% |
| RF 챔피언 MAE | 3,971 W |

### 결론: 채택 불가

논문은 744개 1개월 단일 건물 데이터라 저희 35,000개 4년치 복잡한 부지 전체 데이터에 그대로 적용 불가. RF 챔피언 대비 MAE 150배 차이. **선행연구 근거로만 활용.**

## 6번 논문 — LSTM-AE 이상탐지 (Shrestha et al. 2024)

### 논문 개요
- **논문명**: Anomaly detection based on LSTM and autoencoders using federated learning in smart electric grid
- **핵심 방법론**: LSTM Encoder → latent space → LSTM Decoder → 재구성 오차(MSE) → MSD 임계치로 이상 판정
- **논문 성능**: MSD + 128비트 암호화 결합 시 F1-score 97%, 정확도 98%

### 저희 데이터 적용
- **데이터**: Honda R&D Europe 부지 전체, 1시간 단위
- **분할**: train 2018~2021(정상 데이터만) / test 2023
- **피처**: 개별 계량기 대신 에너지 흐름 단위 그룹 합산 15개 피처 사용
  - grid_P, pv_P, chp_P, heat_total_P, cool_output_P, cool_elec_P, cop, Ta, Igm + 시간 피처 6개
  - **이유**: 81개 × 40항목 피처 과다 방지, 부지 전체 에너지 흐름 관점이 플랫폼 목적에 적합
- **연합학습(FL), 동형암호(HE)**: 저희 범위 외로 제외
- **게이트웨이 장애 구간 4개**: 학습 데이터에서 마스킹 처리

### 실험 결과

| k값 | 이상 건수 | 이상 비율 |
|---|---|---|
| k=3 | 2,180건 | 24.95% |
| k=4 | 1,537건 | 17.59% |
| k=5 | 1,089건 | 12.47% |
| k=6 | 753건 | 8.62% |

- MSD 임계치 (k=3): 0.002779
- 학습 오차 평균: 0.000876 / std: 0.000635

### 의미 있는 탐지 사례

**2023-09-20 (명확한 이상 구간)**
- V.Z81: 11시 -11,158W, 12시 -7,351W, 21시 -13,777W (음수 소비값 → 물리적 이상)
- LSTM-AE: 임계치 대비 최대 47배 오차, 하루 전체 패턴 이상 탐지 ✓
- 통계 기반: 08~10시 low 3건만 탐지 ✗
- **해석**: LSTM-AE가 음수값 포함된 하루 전체 패턴의 이상을 올바르게 탐지

**2023-01-15 (역송전 정상 구간)**
- V.Z81: 하루 종일 -50,000 ~ -80,000W (역송전으로 인한 정상적 음수)
- LSTM-AE: 이상 탐지 0건 → 정상으로 올바르게 판단 ✓
- **해석**: 음수 자체가 아니라 패턴의 불규칙성을 탐지

**2023-12-06, 12-07 (패턴 불규칙 구간)**
- 전체적으로 역송전(음수)이지만 특정 시간대 갑자기 양수로 크게 튀는 패턴
- LSTM-AE: 이상 탐지 ✓
- **해석**: 2023-01-15처럼 일정한 음수 패턴은 정상, 불규칙하게 튀는 패턴은 이상

### 통계 기반 vs LSTM-AE 비교 (2023년 test 기준, k=6)

| 항목 | 값 |
|---|---|
| LSTM-AE 이상 날짜 | 71일 |
| 통계 기반 이상 날짜 | 176일 |
| 겹치는 날짜 | 40일 |
| 통계기반만 탐지 | 136일 |
| LSTM-AE만 탐지 | 31일 |

**두 방법의 근본적 차이**
- 통계 기반: "이 값이 이 데이터 분포에서 극단적인가" → 사전 학습 없음
- LSTM-AE: "이 패턴이 학습된 정상과 다른가" → 새 회사 데이터 적용 시나리오에 적합

### 한계
- 라벨 없는 비지도 학습이라 정확도 직접 측정 불가
- k값 설정에 따라 탐지 비율이 8~25%로 크게 달라짐
- Heat Modernization(2023-06-01) 이후 Regime 변화 구간 일부 놓침
- 학습 기간(2018~2021) 이후 새 정상 패턴 미반영

### 결론: 채택

새로운 회사 데이터를 업로드했을 때 사전 학습된 정상 패턴으로 이상을 판단하는 구조가 플랫폼 목적과 일치. 실제 이상 구간을 의미 있게 탐지했으며 정상적인 역송전 구간은 정상으로 올바르게 판단. **k=6 기준으로 최종 채택.**

## LSTM-AE v1 vs v2 비교 실험

### 실험 목적
논문(Shrestha et al. 2024)은 개별 계량기 값을 그대로 입력으로 사용. 저희 v1은 에너지 흐름 단위 그룹 합산 15개 피처를 사용했는데 이 설계가 임의적인지 검증하기 위해 논문 방식 그대로 전체 계량기 전체 측정항목으로 v2 실험 진행.

### v2 실험 설정
- **피처**: 전체 계량기 × 전체 측정항목 피벗 (train 1,330개 / test 1,558개 / 공통 1,289개)
- **모델 파라미터**: 468,137개 (v1 대비 약 8배)
- **나머지 설정**: v1과 동일 (TIMESTEP=24, EPOCHS=50, BATCH_SIZE=8, K_MSD=3)

### v2 실험 결과

| 항목 | v1 (그룹 합산 15개 피처) | v2 (전체 1,289개 피처) |
|---|---|---|
| 임계치 | 0.002779 | 0.013141 |
| 이상 탐지 건수 | 2,180건 | 8,736건 |
| 이상 탐지 비율 | 24.95% (k=3) / 8.62% (k=6) | **100%** |
| 이상 날짜 수 | 149일 (k=3) / 71일 (k=6) | 364일 |

### 결론: v1 그룹 합산 방식이 맞는 선택

논문 방식 그대로(1,289개 피처) 적용하면 모델이 정상 패턴을 학습하지 못해 100% 과탐지 발생. 피처가 너무 많으면 LSTM-AE가 재구성 오차를 줄이지 못하고 모든 시퀀스를 이상으로 판단.

에너지 흐름 단위로 그룹 합산해 15개 피처로 줄인 것은 자의적인 선택이 아니라 실험적으로 검증된 설계. v2 실험이 v1 설계의 근거가 됨.

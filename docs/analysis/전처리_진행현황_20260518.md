## 3. 단계별 처리 내용

### 1단계: 입력 검증 (validate_input)
- ts, meter_urn, measurement, value 필수 컬럼 확인

### 2단계: 기본 정제 (basic_clean)
- timestamp UTC 정렬
- 중복 제거 (ts, meter_urn, measurement 기준)
- NULL 제거

### 2단계: 부호 규약 (apply_sign_convention)
- 소비 계량기 음수값 → quality_flag = "negative_consumption"
- 발전 계량기 7개 제외: H1.Z20, H1.ZE20, V.Z84, V.ZE84, H1.Z310, H2.Z311, H3.Z312

### 3단계: 변류기 오류 보정 (apply_ct_corrections)
- H2.Z311: ×0.8 (2020-06-25~2021-03-01)
- H4.ZE50/51: ×0.75 (2022-03-22~)
- H1.Z19: 0값 고착 처리 (2022-03-01 08:15 UTC 이후)

### 4단계: 이상 구간 플래그 (flag_anomalies)
- COVID lockdown: is_building_event = True (2020-03-16~2021-01-17)
- 0값: is_outage = True
- IQR 이상치: is_iqr_outlier = True (1.5×IQR 기준, 자의적)

### 4단계 보완: EDA 이상치 처리 (apply_eda_corrections)

| 처리 유형 | 대상 | 내용 |
|---------|------|------|
| 절댓값 처리 | H1.Z15, H1.Z28 I/P | 변류기 방향 오류 전 기간 |
| 절댓값 처리 | H1.Z10 등 7개 WQ | 음수 고착 전 기간 |
| 절댓값 처리 | H1.Z12 등 6개 개별 항목 | 음수 누적값 |
| 제거 | V.Z81 W_in | 정수형 오버플로우 |
| NaN 처리 | H2.T.Z34 U1~U3, f | 2020-03-07~09 완전 정전 |
| NaN 처리 | H2.ZE66/67 PF | 2022-03-01~ PF>1 계산 오류 |
| 플래그 | H2.ZE74 U2 | 2022-03-18~04-09 단상 전압 76V |

### 4단계 보완: 물리적 기준 처리 (apply_physical_constraints)

| 처리 유형 | 대상 | 기준 |
|---------|------|------|
| 플래그 | Q | 음수 무효전력 |
| 플래그 | 냉방 계량기 Tdiff | 양수 불가 (mK 기준) |
| 플래그 | 난방 계량기 Tdiff | 음수 불가 (mK 기준) |
| NaN 처리 | Trl, Tvl | -20°C 미만 또는 120°C 초과 |
| 플래그 | qv | 음수 유량 |
| 플래그 | f | 49.5Hz 미만 또는 50.5Hz 초과 (EN 50160) |
| 플래그 | U1, U2, U3 | 207V 미만 또는 253V 초과 (EN 50160) |
| NaN 처리 | PF, PF1~3 | -1 미만 또는 1 초과 |

## 4. 5단계 파생변수 (build_imbalance_features, build_time_features)

run_pipeline에서 분리. wide format 전환 후 별도 호출 구조.

### 확정 파생변수
- I_imbalance = std(I1, I2, I3)
- PF_imbalance = std(PF1, PF2, PF3)
- P_I_ratio = P / mean(I1, I2, I3)
- delta_W = W.diff()
- Tdiff_calc = Tvl - Trl (센서 노이즈 대안)

### 자의적 파생변수 (팀 논의 필요)
- 시간 피처: hour, day_of_week, month, is_weekend, season, sin/cos encoding
- rolling: 1h/6h/24h/7d (4/24/96/672 ticks)
- lag: 1/4/96/672 ticks (15min 기준 15분/1h/24h/7d)

---

## 5. 자의적 설정 항목 (팀 논의 필요)

| 항목 | 설정값 | 이유 |
|------|-------|------|
| IQR 기준 | 1.5×IQR | 박스플롯 표준 기준 |
| LAG_TICKS | [1, 4, 96, 672] | 15min 기준 15분/1h/24h/7d 패턴 포착 |
| ROLLING_WINDOWS | 1h/6h/24h/7d | 단기~주간 트렌드 포착 |
| build_time_features | UTC 기준 | 로컬 타임 변환 기준 미확정 |
| Tdiff_calc | Tvl - Trl | Tdiff 센서 노이즈 대안 |

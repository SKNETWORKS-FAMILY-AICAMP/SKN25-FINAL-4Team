# Meter Description Table

이 문서는 계량기 이름, 계통 역할, 상위/하위 관계, 운영 해석 포인트, 모델링 권장사항까지 포함한 현재 기준 문서입니다.
명시되지 않은 상위/하위 관계는 메타데이터 기반의 일반 해석이며, `assumption_note`가 있는 항목은 사용자 설명 또는 운영 추정이 반영된 것입니다.

## 컬럼 해석
- `role_summary`: 그룹 수준 역할 요약
- `system_role`: 해당 계량기의 보다 직접적인 설비 역할
- `directionality`: 단방향/양방향 가능 여부
- `upstream_relation`, `downstream_relation`: 상위/하위 계통 관계
- `ops_interpretation`: 그래프/EDA 해석 시 먼저 봐야 할 포인트
- `modeling_recommendation`: 이상탐지/예측 모델링 시 권장 방향

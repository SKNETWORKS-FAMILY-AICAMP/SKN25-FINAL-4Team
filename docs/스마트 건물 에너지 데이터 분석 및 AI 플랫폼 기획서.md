# **스마트 건물 에너지 데이터 분석 및 대화형 AI 플랫폼 기획서**

본 문서는 Honda R\&D Europe 시설의 6년 치(2018\~2023) 스마트 건물 에너지 관리 데이터셋 논문 분석 결과와, 이를 바탕으로 한 '중소 제조업 대상 대화형 에너지 분석 에이전트 플랫폼' 구축 로드맵을 정리한 내용입니다.

## **1\. 에너지 데이터셋 구조 및 전처리 이해**

대규모 실제(Real-World) 에너지 데이터를 분석하고 활용하기 위해, 센서 데이터는 목적에 따라 여러 정제 단계를 거쳐 제공됩니다.

| 데이터셋 종류 | 특징 및 활용 방안   |
| :---- | :---- |
| **Raw 데이터** | 가공되지 않은 원시 데이터. 이상 탐지(Anomaly Detection) 및 기기 고장 진단 모델의 학습용(정답지)으로 적합. |
| **Harmonized 데이터** | 다양한 제조사와 설치 오류로 인해 제각각인 부호(+/-)와 단위를 일관된 기준(양수는 소비, 음수는 생산)으로 조화(Harmonization)시킨 데이터. |
| **Corrected 데이터** | 통신 단절, 결측치(Gap), 비정상적 값 도약(Leap) 등의 오류를 복제 간격 채우기 등으로 보정하고 시간 오차를 맞춘 데이터. |
| **Reduced 데이터** | 수많은 계량기 데이터를 전기, 난방, 냉방, 기상의 4대 범주로 압축 합산한 데이터. 전반적인 에너지 트렌드 및 예측 모델 초기 설계에 적합. |

## **2\. 전기 에너지 핵심 지표 분석**

### **역률(Power Factor)과 무효 에너지(Reactive Energy)**

전기 에너지를 얼마나 낭비 없이 사용하고 있는지를 나타내는 효율 지표입니다. 교류 전력망에서 기기가 자기장을 형성하기 위해 주고받는 실제 일을 하지 않는 에너지를 무효 에너지라고 합니다.

* **지상 부하 (Inductive Load):** 공장 모터나 냉각기 등 무효 에너지를 '소비'하여 역률을 깎아먹는 부하입니다.  
* **진상 부하 (Capacitive Load):** 커패시터(콘덴서) 등 무효 에너지를 '공급'하여 무너진 역률을 보상하는 해독제 역할을 합니다. 단, 과보상 시 페란티 현상(과전압)을 유발하므로 관리가 필수적입니다.  
* **마이너스 역률:** 태양광(PV) 인버터 등이 전기를 전력망으로 밀어내는 '생산(역송전)' 상태일 때 주로 발생합니다.

### **데이터 패턴의 원인 분석**

* **2019년 중반 WQ\_out 증가:** 2019년 6월 첫 태양광(PV) 시스템 가동으로 인해 인버터가 진상 무효 전력을 전력망으로 반환(공급)하기 시작하면서 0이던 수치가 유의미하게 증가했습니다.  
* **H1.Z24 (냉각기 3.1) 특성:** 대형 모터로 인해 기본적으로 무효 에너지를 소비(WQ\_in)하지만, 인버터(VFD)나 개별 진상용 콘덴서의 영향으로 대기 상태 등에서 미세한 WQ\_out이 발생할 수 있습니다. 해당 기기의 총 무효 에너지는 계량기 직접 측정이 아닌 계산된 파생 변수입니다.

## **3\. 대화형 에너지 분석 에이전트 플랫폼 기획**

### **시스템 아키텍처 및 DB 선정**

제조업 특성상 On-Premise 하이브리드 구조(NAS 데이터 적재, k3s 오케스트레이션, 고성능 노드 로컬 LLM 구동)가 적합합니다.  
시계열 DB의 경우 초고속 쓰기에는 InfluxDB가 유리하지만, **AI 에이전트 중심의 플랫폼에서는 TimescaleDB가 압도적으로 유리**합니다. LLM이 가장 잘 이해하고 생성할 수 있는 표준 SQL(PostgreSQL)을 지원하며, 장비 메타데이터와 시계열 데이터를 JOIN하여 융합 분석하기 쉽기 때문입니다.

### **멀티 에이전트(Multi-Agent) 구성**

1. **데이터 분석 에이전트 (Data Analyst):** 사용자의 자연어 질문을 Text-to-SQL로 변환하여 데이터를 추출 및 시각화.  
2. **이상 탐지 에이전트 (Anomaly Hunter):** Raw 데이터를 백그라운드 모니터링하여 역률 저하 및 전력 도약 징후 즉각 경고.  
3. **비용 최적화 에이전트 (Cost Optimizer):** 진상/지상 부하 밸런스를 분석하여 역률 할증 방지 및 비용 절감 액션 플랜 제시.  
4. **자동 리포팅 에이전트 (Report Generator):** 분석 결과와 핵심 지표를 모아 경영진 맞춤형 주간 요약 보고서 자동 생성.

### **5단계 플랫폼 개발 로드맵**

| 단계 | 목표 및 주요 작업   |
| :---- | :---- |
| **Phase 1** | **DB 스키마 설계:** 장비 메타데이터 및 시계열 테이블(TimescaleDB) 정의. 초기 Reduced 데이터 적재. |
| **Phase 2** | **분석 에이전트 튜닝:** Reduced 데이터를 활용해 Text-to-SQL 성능 테스트 및 기본 트렌드 EDA. |
| **Phase 3** | **비용 최적화 로직 구현:** 무효 에너지 분석을 통한 역률 과태료 방지 및 진상 콘덴서 제어 룰 적용. |
| **Phase 4** | **이상 탐지 모델링:** Raw 데이터와 Labeled Issues 정답지를 활용해 기기 고장 전조 증상 학습 및 알림 연동. |
| **Phase 5** | **자동 리포팅 파이프라인:** 주기적 배치 작업을 통한 경영진 요약 스토리텔링 문서 자동 생성기 완성. |

**결론:** 본 프로젝트는 중소 제조업의 에너지 관리 페인 포인트를 실질적으로 해결할 수 있는 강력한 접근입니다. 고품질의 공개 데이터셋을 활용해 에이전트의 뼈대를 성공적으로 구축하시길 바랍니다.

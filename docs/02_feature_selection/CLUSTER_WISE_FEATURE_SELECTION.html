해석 메모

  • 이번 결과는 전체 대표 계량기 집합을 한 번에 본 것이 아니라, 각 군집 내부에서만 다시 feature selection을 한 결과입니다.
  • 따라서 같은 소비 계량기라도 C2와 C12는 대표 feature 구성이 달라질 수 있습니다.
  • W / W_in / W_out은 누적 성격이 강하므로, 상관이 높더라도 이상탐지 입력 feature로 바로 쓰기보다는 제외 또는 보조 지표로 두는 편이 안전합니다.
  • Ta, Igm은 대부분 단독으로 남았습니다. 즉 전기 계량기 내부 feature 중복 제거 관점에서는 별도 축으로 보는 것이 맞습니다.
  • 대표 feature는 순수 상관 기준으로 뽑았기 때문에 일부 군집에서는 P 대신 Q, I2, I3, P2 같은 값이 대표로 선택됐습니다.
생성 목적: 군집별 예측/이상탐지 모델 입력 feature를 각 군집 단위로 다시 좁혀보기 위한 중간 정리 문서.

## 1. Reduced Aggregated View 생성 (✅ 완료)

논문(Table 8)에서 명시된 건물 전체 수준의 에너지 흐름(전기, 난방, 냉방, 기상)을 파악할 수 있는 통합 뷰를 DB에 생성했습니다.

- **산출물**: [scripts/ingest/sql/reduced_view.sql](file:///Users/khl/workspace/EMS/scripts/ingest/sql/reduced_view.sql)
- **생성된 뷰**:
  - `ems.reduced_measurement_15min` (15분 해상도)
  - `ems.reduced_measurement_1h` (1시간 해상도)
- **조회 방법 예시**:
  ```sql
  SELECT ts, category, subcategory, measurement, value 
  FROM ems.reduced_measurement_15min 
  WHERE category = 'electricity' AND subcategory = 'pv'
  ```

> [!TIP]
> 기존에는 개별 미터(예: `V.Z81`, `H2.Z35` 등)를 일일이 찾아서 더해야 했지만, 이제 이 뷰를 통해 `category='electricity'`, `subcategory='total'` 조건만으로 간편하게 전체 소비량을 조회할 수 있습니다.

## 2. 기상 데이터 외부 보완 스크립트 (✅ 완료)

독일 기상청(DWD) Climate Data Center에서 직접 과거 기상 데이터를 다운로드하여 병합하는 파이프라인 코드를 작성했습니다.

- **산출물**: [scripts/ingest/dwd_weather_ingest.py](file:///Users/khl/workspace/EMS/scripts/ingest/dwd_weather_ingest.py)
- **기능**:
  - 관측소 `07341` (Offenbach)의 기온(Ta) 및 일사량(Igm) Historical 압축 파일 탐색 및 다운로드
  - DWD의 특수 포맷(세미콜론 구분자, `-999` 결측치) 파싱
  - 일사량 단위 변환 (`J/cm²` → `W/m²`)
  - `MESS_DATUM`을 UTC Timestamp로 변환 후 병합하여 CSV로 저장 (`outputs/tables/dwd_weather_07341.csv`)

> [!NOTE]
> 현재 로컬 네트워크의 외부 인터넷 접근 제한(DNS Resolution 이슈)으로 인해 다운로드 로직을 직접 실행하여 CSV를 추출하지는 못했습니다. 방화벽이 열려있거나 인터넷이 허용된 환경에서 스크립트를 실행하시면 즉시 데이터가 생성됩니다.

## 3. Synthetic Flag (인공 보정 구간 식별) (⚠️ 보류)

> [!WARNING]
> 원본(raw) 데이터와 보정(corrected) 데이터를 비교하여 인공적으로 채워진 구간을 찾아내는 작업을 계획했으나, **현재 DB (`ems.full_measurement`)에는 `processing_level = 'raw'` 데이터가 적재되어 있지 않음**을 확인했습니다.

DB 조회 결과, 오직 `corrected_resampled` 단계의 데이터만 약 3,481개의 파일로부터 로드되어 있었습니다. 원본 결측치를 알아내려면 Raw 데이터가 DB에 있거나, 논문에서 제공하는 라벨링 파일(`manual_issues.yaml`, `automatic_issues.yaml`)을 로드해야 합니다.

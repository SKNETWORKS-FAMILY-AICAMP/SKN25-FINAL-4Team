# EMS 프로젝트 진행 현황

지금까지 **논문과 기획서를 바탕으로 데이터의 한계를 파악하고, 분석을 위한 뼈대를 세우는 작업**을 집중적으로 진행했습니다.

---

## 완료된 작업

### ✅ 데이터 100% 전수 조사 및 프로파일링
- 전체 **81개 계량기**의 약 6년 치 데이터를 스캔하여 품질을 진단
- 에너지 미터 결측률 0%, 기상 데이터만 결측(2.35%) 잔존 확인
- 게이트웨이 장애 구간이 '과거 데이터 복사'로 전부 메워져 인공 데이터 식별 필요성 규명
- 📄 상세: `03_프로파일링_결과.md`

### ✅ 건물 단위 거시적 통합 뷰 (Reduced View) 생성
- **논문 Table 8 기준** 전기/난방/냉방/기상 4대 범주별 합산 DB 뷰 생성
- `ems.reduced_measurement_15min`, `ems.reduced_measurement_1h`
- 📄 상세: `04_뷰생성_및_보완_결과.md`

### ✅ 에너지 흐름 시각화 검증 (6개 차트)
- 전기 6년 추이, 난방/냉방 계절 패턴, 기상 데이터, 월별 수지, 대표 주간, 냉각-기온 상관
- 📄 상세: `05_에너지_흐름_시각화.md`

### ✅ 기상 데이터 보완 파이프라인 준비
- 독일 기상청(DWD) API 연동 스크립트 작성 완료 (네트워크 환경에서 실행 대기)

## 남은 과제

| 과제 | 상태 | 비고 |
|------|------|------|
| 인공 보정 구간(Synthetic) 식별 | ⚠️ 보류 | DB에 Raw 데이터 미존재. YAML 라벨 파일 적재 필요 |
| DWD 기상 데이터 실행 | ⏳ 대기 | 외부 인터넷 접근 가능 환경에서 실행 |
| Text-to-SQL 에이전트 개발 | 🔜 Phase 2 | 팀원들과 추후 진행 |
| 역률/비용 최적화 | 🔜 Phase 3 | 한국 전기요금 기준 적용 필요 |
| 이상 탐지 모델링 | 🔜 Phase 4 | Raw 데이터 + 라벨 확보 후 |

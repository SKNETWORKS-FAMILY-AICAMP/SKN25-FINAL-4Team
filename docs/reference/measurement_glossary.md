# Measurement Glossary

**갱신일:** 2026-06-02  
**상태:** 측정값 도메인 용어집  
**범위:** 이 문서는 전기/열/기상 measurement를 해석하기 위한 참고 용어를 정리한다. Active runtime naming은 `CMS`를 사용한다.

**갱신일:** 2026-05-15  
**범위:** CMS measurement 코드 중 전기 계열을 이해하기 위한 도메인 참조 노트. 이 문서는 분석 결과나 feature 명세가 아니라 전기 물리량의 기본 의미를 정리한다.

---

## 1. 기본 관계

CMS 전기 measurement를 이해할 때 먼저 볼 개념은 다음 7개다.

| 개념 | 기호 | CMS measurement | 단위 | 의미 |
|---|---|---|---|---|
| 전압 | `U` | `U1`, `U2`, `U3` | `V` | 전류를 흐르게 하는 전위차 |
| 전류 | `I` | `I1`, `I2`, `I3` | `A` | 단위 시간당 흐르는 전하량 |
| 유효전력 | `P` | `P`, `P1`, `P2`, `P3` | `W` | 실제 일을 하는 전력 |
| 무효전력 | `Q` | `Q` | `var` | 전기장·자기장 형성에 오가는 전력 |
| 피상전력 | `S` | 직접 measurement 없음 | `VA` | 전압과 전류로 결정되는 전체 전력 크기 |
| 역률 | `PF` | `PF`, `PF1`, `PF2`, `PF3` | 없음 | 피상전력 중 유효전력의 비율 |
| 전력량 | `W` | `W`, `W1`, `W2`, `W3`, `W_in`, `W_out` | `kWh` | 유효전력을 시간에 대해 누적한 에너지량 |

핵심 관계는 다음과 같다.

```text
U, I → S
S → P + Q
PF = P / S
W = ∫ P dt
```

---

## 2. 전압 `U`

전압은 전류를 흐르게 하는 전위차다. 물 흐름에 비유하면 수압에 가깝다.

| CMS code | 의미 |
|---|---|
| `U1` | 1상 전압 |
| `U2` | 2상 전압 |
| `U3` | 3상 전압 |

전기공학에서는 전압을 `U`로 표기하는 경우가 많다. CMS에서는 `V`가 체적 또는 volume 계열 measurement로 쓰이므로, 전압은 `U`, 체적은 `V`로 구분한다.

---

## 3. 전류 `I`

전류는 단위 시간당 흐르는 전하량이다. 물 흐름에 비유하면 배관을 흐르는 물의 양에 가깝다.

| CMS code | 의미 |
|---|---|
| `I1` | 1상 전류 |
| `I2` | 2상 전류 |
| `I3` | 3상 전류 |

전류가 크다는 것은 보통 부하가 크거나, 선로와 장비에 흐르는 전기적 부담이 크다는 뜻이다. 다만 전류가 크다고 해서 항상 유효전력이 같은 비율로 큰 것은 아니다. 역률이 낮으면 전류가 커도 실제 일을 하는 전력은 상대적으로 작을 수 있다.

---

## 4. 유효전력 `P`

유효전력은 실제 일을 하는 전력이다. 열, 빛, 회전, 냉각, 연산 등으로 전환되는 전력이다.

| CMS code | 의미 |
|---|---|
| `P` | 전체 유효전력 |
| `P1` | 1상 유효전력 |
| `P2` | 2상 유효전력 |
| `P3` | 3상 유효전력 |

직류에서는 다음과 같이 계산한다.

```text
P = U × I
```

교류에서는 전압과 전류의 위상차를 반영해 역률을 곱한다.

```text
P = U × I × PF
```

3상 계통에서는 전체 유효전력이 각 상 유효전력의 합과 대체로 대응한다.

```text
P ≈ P1 + P2 + P3
```

---

## 5. 무효전력 `Q`

무효전력은 실제 일을 하지는 않지만 전기장이나 자기장을 만들기 위해 전원과 부하 사이를 오가는 전력이다.

| CMS code | 의미 |
|---|---|
| `Q` | 무효전력 |

모터, 변압기, 코일 부하에서는 자기장을 만들기 위해 무효전력이 필요하다. 무효전력은 불필요한 값이라는 뜻이 아니라, 실제 일로 소비되지는 않지만 장비 동작에 필요한 전력 성분이다.

무효전력이 커지면 전선과 변압기에는 전류 부담이 생기지만, 그만큼의 전력이 열·회전·빛 같은 실제 일로 전환되지는 않는다. 이 경우 역률이 낮아질 수 있다.

---

## 6. 피상전력 `S`

피상전력은 전압과 전류를 곱한 전체 전력 크기다. CMS measurement에는 `S`가 직접 존재하지 않지만, `P`, `Q`, `PF`를 이해하기 위한 핵심 개념이다.

```text
S = U × I
```

단위는 `VA`다. 변압기 용량을 `kVA`로 표현하는 이유는 설비가 감당해야 하는 전체 전기적 크기가 유효전력만이 아니라 피상전력과 관련되기 때문이다.

---

## 7. 전력 삼각형

유효전력, 무효전력, 피상전력은 다음 관계를 가진다.

```text
          S 피상전력
         /
        /
       /
      /
     / φ
    └──────── P 유효전력
    |
    |
    Q 무효전력
```

관계식은 다음과 같다.

```text
S² = P² + Q²
PF = P / S
```

전류가 흐른다고 해서 그 전류가 모두 실제 일로 전환되는 것은 아니다. 피상전력 중 실제 일을 하는 비율이 역률이다.

---

## 8. 역률 `PF`

역률은 피상전력 중 유효전력이 차지하는 비율이다.

| CMS code | 의미 |
|---|---|
| `PF` | 전체 역률 |
| `PF1` | 1상 역률 |
| `PF2` | 2상 역률 |
| `PF3` | 3상 역률 |

계산식은 다음과 같다.

```text
PF = P / S
```

이상적인 정현파 교류에서는 전압과 전류 사이의 위상차 `φ`를 사용해 다음처럼 표현할 수 있다.

```text
PF = cos φ
```

역률이 1에 가까우면 전체 전력 흐름 중 실제 일에 쓰이는 비율이 높다. 역률이 낮으면 전류는 많이 흐르지만 실제 유효전력 비율은 낮고, 선로와 변압기에 불필요한 부담이 커질 수 있다.

---

## 9. 전력량 `W`

전력량은 유효전력을 시간에 대해 누적한 에너지량이다.

| CMS code | 의미 |
|---|---|
| `W` | 유효전력량 |
| `W1` | 1상 유효전력량 |
| `W2` | 2상 유효전력량 |
| `W3` | 3상 유효전력량 |
| `W_in` | 유입 방향 유효전력량 |
| `W_out` | 유출 방향 유효전력량 |

전력과 전력량의 관계는 다음과 같다.

```text
W = ∫ P dt
```

비유하면 `P`는 순간 속도, `W`는 이동 거리다.

| 구분 | 의미 |
|---|---|
| `P = 10 kW` | 순간적으로 10 kW 속도로 에너지를 쓰는 상태 |
| `W = 10 kWh` | 일정 기간 누적 사용량이 10 kWh인 상태 |

---

## 10. 방향성: `W_in`, `W_out`

전력량은 계량기를 기준으로 방향을 가질 수 있다.

| CMS code | 의미 |
|---|---|
| `W_in` | 계량기 기준으로 들어온 유효전력량 |
| `W_out` | 계량기 기준으로 나간 유효전력량 |

소비 설비에서는 전력망에서 설비 쪽으로 전기가 들어오므로 `W_in`이 중요하다. 발전 설비에서는 PV나 CHP에서 건물 또는 전력망 쪽으로 전기가 나갈 수 있으므로 `W_out`이나 생산 방향 부호가 중요하다.

`in`, `out`은 값의 좋고 나쁨이 아니라 계량기 기준 전력 흐름 방향을 나타낸다.

---

## 11. 무효전력량 `WQ`

무효전력도 시간에 대해 누적한 값이 있다.

| CMS code | 의미 |
|---|---|
| `WQ` | 무효전력량 |
| `WQ_in` | 유입 방향 무효전력량 |
| `WQ_out` | 유출 방향 무효전력량 |

관계는 다음과 같다.

```text
WQ = ∫ Q dt
```

---

## 12. 3상 표기

CMS에서 `1`, `2`, `3`이 붙은 measurement는 3상 전기의 각 상을 뜻한다.

```text
U1, U2, U3
I1, I2, I3
P1, P2, P3
PF1, PF2, PF3
W1, W2, W3
```

큰 건물, 냉각기, 모터, 서버 전원 설비는 보통 3상 전기를 사용한다. 각 상은 같은 주파수를 가지지만 위상이 120도씩 어긋난다.

```text
L1:   0°
L2: 120°
L3: 240°
```

전체값과 상별값의 관계는 다음과 같이 이해한다.

```text
P ≈ P1 + P2 + P3
W ≈ W1 + W2 + W3
```

상별 전류나 전력이 크게 다르면 상 불평형을 의심할 수 있다.

---

## 13. 핵심 요약

```text
U는 밀어주는 힘이다.
I는 흐르는 양이다.
S는 전체 전력 크기다.
P는 실제 일하는 전력이다.
Q는 실제 일은 하지 않고 전기장·자기장에 오가는 전력이다.
PF는 전체 전력 중 실제 일하는 비율이다.
W는 유효전력을 시간에 대해 누적한 값이다.
```

CMS measurement에 매핑하면 다음과 같다.

| 개념 | CMS measurement |
|---|---|
| 전압 | `U1`, `U2`, `U3` |
| 전류 | `I1`, `I2`, `I3` |
| 유효전력 | `P`, `P1`, `P2`, `P3` |
| 무효전력 | `Q` |
| 역률 | `PF`, `PF1`, `PF2`, `PF3` |
| 유효전력량 | `W`, `W1`, `W2`, `W3`, `W_in`, `W_out` |
| 무효전력량 | `WQ`, `WQ_in`, `WQ_out` |
| 주파수 | `f` |

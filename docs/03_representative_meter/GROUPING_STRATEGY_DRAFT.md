# Grouping Strategy Draft

이 문서는 `B 방식`(군집을 하나의 그룹 모델로 학습)과 `C 방식`(계량기 정체성은 유지하고 모델 파라미터를 공유) 적용을 위한 1차 추천 군집 초안이다.

## 원칙
- `B 방식`은 가능한 한 좁고 보수적으로 묶는다.
- `C 방식`은 처음에는 B와 같은 군집으로 시작하고, 필요 시 일부 군집만 넓혀서 실험한다.
- `H1.Z15`, `H1.Z17`, `H1.Z28`, `H1.Z29`는 양방향 feed/dist 성격으로 공통 군집 모델에서 제외한다.
- `WeatherStation.Weather`는 모델 대상이 아니라 외생 변수 소스로만 사용한다.

## 메모
- `B 방식`은 위 군집을 그대로 사용하는 것이 1차 추천이다.
- `C 방식`은 위 군집으로 시작하되, 후속 실험에서 일부 군집만 더 넓게 합칠 수 있다.
- 군집을 넓힌다고 성능이 자동으로 좋아지는 것은 아니다. 넓은 군집은 모델 수 감소와 일반화 측면의 장점이 있지만, 성능은 반드시 실험으로 확인해야 한다.

## 예측 LSTM용 타 계량기 P feature 추가 기준

이 섹션은 `A 방식`을 예측 LSTM에 적용할 때, 어떤 다른 계량기의 `P`를 입력 feature로 추가할지 정하는 기준이다.

### 기본 원칙
- 1차 기준은 `같은 군집`이다.
- 2차 기준은 `물리적 연결성`이다.
- 3차 기준은 `위치(prefix: H1/H2/H3/H4/V)`를 보조 필터로 사용한다.
- `다른 계량기 P`는 무조건 많이 넣는 것보다, 소수의 관련 계량기만 선별하는 것이 좋다.

### 우선순위
1. 같은 군집의 계량기
2. 상위/하위 계통 관계가 있는 계량기
3. 같은 위치(prefix)를 공유하는 관련 계량기
4. 이중화(redundant pair) 계량기

### 왜 이런 기준을 쓰는가
- `같은 군집`:
  - 물리 역할이 가장 비슷하고 패턴 공유 가능성이 높다.
  - 예: 중앙 냉각기끼리는 같은 시간대, 같은 외기 조건에서 같이 움직일 가능성이 크다.
- `물리적 연결성`:
  - 예측은 단순 상관보다 실제 계통 연결성이 있을 때 더 안정적으로 도움이 될 가능성이 높다.
  - 예: 상위 transformer / distribution / feed 계량기의 `P`는 하위 부하 예측에 설명력이 있을 수 있다.
- `위치(prefix)`:
  - 위치가 같으면 동일 운영 구역/하위 배전 그룹일 가능성이 있어 우선순위를 조금 높일 수 있다.
  - 다만 위치는 1차 기준이 아니라 보조 기준이다.
- `redundant pair`:
  - 같은 회로를 중복 계측하는 경우가 있어 feature 후보가 될 수 있다.
  - 단, 강한 중복 정보라서 예측 성능 향상보다 누수/과한 중복 여부를 먼저 점검해야 한다.

### 추천 선택 방식
- 한 계량기 예측 모델에 타 계량기 `P`를 추가할 때는 보통 `1~3개` 정도의 소수 feature부터 시작한다.
- 처음부터 군집 전체의 모든 `P`를 넣지 않는다.
- 추천 순서:
  1. 같은 군집 내 가장 직접적으로 관련된 계량기 `P`
  2. 필요하면 상위 계통 `P`
  3. 필요하면 redundant pair `P`

### 예시

#### H1.Z16 예측
- 본인 feature:
  - `H1.Z16_P`, `H1.Z16_PF`, `H1.Z16_I1`, `H1.Z16_I2`, `H1.Z16_I3`, `Ta`, `Igm`, 시간 파생변수
- 추가 후보:
  - `H1.Z11_P`
  - `H1.Z12_P`
  - 필요 시 `H1.Z24_P` 또는 `H1.Z25_P`

이유:
- 모두 `cooling_central_electric` 군집
- 중앙 냉각기 계통으로 같은 운전 패턴을 공유할 가능성이 높음
- 같은 `H1` prefix로 위치/하위 배전 구역도 가까울 가능성이 큼

#### H2.Z61 예측
- 본인 feature:
  - `H2.Z61_P`, `H2.Z61_PF`, `H2.Z61_I1`, `H2.Z61_I2`, `H2.Z61_I3`, `Ta`, `Igm`, 시간 파생변수
- 추가 후보:
  - `H2.Z62_P`
  - `H2.Z63_P`
  - 필요 시 상위 `H2.Z35_P` 또는 `H2.Z36_P`

이유:
- 같은 `server_electric` 군집
- 같은 `H2` prefix
- 상위 transformer 계통과 물리 연결 가능성

#### H1.Z20 예측
- 본인 feature:
  - `H1.Z20_P`, `H1.Z20_PF`, `H1.Z20_I1`, `H1.Z20_I2`, `H1.Z20_I3`, `Ta`, `Igm`, 시간 파생변수
- 추가 후보:
  - `H1.ZE20_P`

이유:
- 같은 `chp_production` 군집
- redundant pair 관계
- CHP 전기 생산 패턴을 보조 설명 가능

### 주의
- 타 계량기 `P`를 많이 넣을수록 설명력이 자동으로 좋아지는 것은 아니다.
- feature 수가 너무 늘면:
  - 과적합
  - 해석 어려움
  - 결측 처리 복잡도 증가
  가능성이 커진다.
- 따라서 예측 LSTM의 `A 방식`은 `같은 군집 + 물리 연결성 + 위치 보조 필터` 기준으로 소수의 후보만 넣는 것이 1차 추천이다.

# Overall Representative Meter Selection

기준:

- 입력 파일: `outputs/raw_eda/correlation/analysis/electric_meter_correlation_representative.html`
- 기준 feature: `P`, `U1`, `PF`
- `overall`: 위 3개 feature의 `|corr|` 평균
- 군집 규칙: `docs/02_feature_selection/FEATURE_SELECTION.md` 기준과 동일하게 `Complete Linkage`
- 임계값: `|corr| >= 0.7`
  - 즉 같은 군집 안의 **모든 pair**가 0.7 이상이어야 함
- 대표 계량기 선정:
  - 군집 내부에서 다른 계량기들과의 평균 `overall |corr|`가 가장 높은 계량기를 대표로 선택
  - 단독 계량기는 자기 자신을 대표로 유지

## 해석 메모

- 이번 그룹핑은 **연결만 있으면 묶는 방식이 아니라**, `Complete Linkage` 기준이라 군집 내 모든 pair가 `0.7` 이상이어야 합니다.
- 따라서 `A-B >= 0.7`, `A-C >= 0.7` 이어도 `B-C < 0.7`이면 같은 군집으로 묶지 않았습니다.
- 대표 계량기는 군집 내부 평균 `overall |corr|`가 가장 높은 계량기로 잡았습니다.
- 현재 `overall`은 `P`, `U1`, `PF` 기반이며 `f`는 제외된 상태입니다.

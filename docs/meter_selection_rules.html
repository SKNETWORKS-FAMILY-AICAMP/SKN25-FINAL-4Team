🔥 Rule 2: 열 및 냉방 계량기

Rule 정의
  • 변수: P (열량), Tdiff (온도차), qv (유량) — 3변수로 이상치 탐지 모형 구성
  • P, Tdiff, qv 간 평균 |corr| ≥ 0.7인 계량기가 존재할 경우:
    • Trigger 발동 → 전기 계량기와 동일하게 가장 최하단 node(leaf)만 선택
    • 해당 계량기와 평균 |corr| ≥ 0.7인 계량기는 분석에서 제외

2.3 Rule 2 적용 순서

Step내용적용
① Trigger H1.W12 internal |corr(P,Tdiff,qv)| = 0.759 ≥ 0.7 발동
② leaf-only 전기 계량기처럼 최하단 node(leaf)만 선택 H1.W12 = leaf → 유지
H1.W11 = parent → 제외
③ cross-corr 제거 H1.W12와 평균 |corr| ≥ 0.7인 계량기 제외 H1.W11과 cross-corr 확인 필요
🔧 수정 내역 (2026-05-21)

초안에서는 "H1.W12 internal corr ≥ 0.7 → H1.W12 자체 제외"로 잘못 적용함.
올바른 해석: internal corr ≥ 0.7은 leaf-only 규칙의 Trigger일 뿐이며, 제거 대상은 parent(H1.W11)이지 leaf(H1.W12)가 아님.

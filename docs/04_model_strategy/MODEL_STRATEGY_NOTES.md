# Model Strategy Notes

## 정의

- `A 방법`
  - 다른 계량기의 `P`값을 feature로 추가하는 방식
  - 예: `H1.Z16` 모델 입력에 `H1.Z11_P`, `H1.Z12_P` 추가

- `B 방법`
  - 여러 계량기를 하나의 그룹 데이터처럼 합쳐서 하나의 모델로 학습하는 방식
  - 계량기별 개별성은 약해지고, 그룹 전체를 하나의 대상처럼 본다
  - 예: `cooling_central` 그룹 전체를 하나의 군집 정상 패턴/예측 대상으로 학습

- `C 방법`
  - 계량기는 따로 유지하되, 같은 구조/같은 파라미터의 모델을 여러 계량기가 공유하며 학습하는 방식
  - 즉 `계량기 정체성은 유지`하면서 `모델만 공유`
  - 예: `Z16`, `Z11`, `Z12` 데이터를 같은 모델에 학습시키지만, 각 샘플이 어느 계량기 것인지는 유지

## 이상탐지 모델별 정리

### 1. STL

- A 방법: 거의 안 맞음
- B 방법: 거의 안 맞음
- C 방법: 거의 안 맞음

이유:
- STL은 단일 시계열 분해 모델이다.
- 핵심 타깃(`P`, `Tdiff`) 하나를 `trend / seasonal / residual`로 나누는 구조라서
  다른 계량기 feature 추가나 군집/공유 모델 개념과 잘 맞지 않는다.

### 2. Isolation Forest (IF)

- A 방법: 적용 가능, 가장 자연스러움
- B 방법: 적용 가능, 특히 `군집별 IF`는 해볼 만함
- C 방법: 가능은 하지만 우선순위는 B보다 낮음

이유:
- IF는 원래 다변량 feature 기반 모델이다.
- `P`, `PF`, `I1~I3`, `Ta`, `Igm`처럼 여러 변수를 함께 보므로
  관련 계량기 `P`를 추가하는 것도 기술적으로 자연스럽다.

주의:
- 성능 보장은 없다.
- 다른 계량기 `P`를 넣는 순간 `단일 계량기 이상탐지`보다
  `관계형/시스템 상태 이상탐지` 성격이 강해진다.
- 해석 난이도가 올라간다.
- B 방식은 `군집 전체 정상 분포`를 배우는 데 유리하지만 계량기별 개성이 약해질 수 있다.
- C 방식은 B보다 계량기 정체성을 유지하기 쉽지만, 현재 IF에서는 B 대비 구현 복잡도 대비 이득이 불분명하다.

### 3. 이상탐지 LSTM

- A 방법: 가능은 하지만 현재는 우선순위 낮음
- B 방법: 가능은 하지만 구현/해석 난이도가 큼
- C 방법: 가능은 하지만 현재는 비추천에 가까움

이유:
- 시계열 패턴 이탈은 볼 수 있지만
  다른 계량기 feature를 넣거나 여러 계량기를 함께 학습시키면
  해석이 더 어려워지고 모델 복잡도가 크게 증가한다.

## 예측 모델 정리

### 예측 LSTM

- A 방법: 매우 자연스럽고 추천
- B 방법: 가능하지만 계량기 개성이 묻힐 위험이 큼
- C 방법: 매우 유력한 후보

이유:
- 예측은 원래 `다른 설비 상태가 내 미래값 예측에 도움이 되는가`를 보는 문제라서
  관련 계량기 `P`를 입력 feature로 넣는 것이 논리적으로 자연스럽다.
- C 방식은 `계량기 정체성은 유지`하면서 `모델 파라미터를 공유`할 수 있어
  예측 정확도와 모델 수 절감 사이의 균형이 좋다.

### Boosting (CatBoost / LightGBM / XGBoost)

- A 방법: 매우 추천
- B 방법: 가능하지만 과감한 단순화 전략
- C 방법: 가장 유력한 최종 후보

이유:
- 현재 feature 구조가 tabular에 매우 잘 맞는다.
- `self feature + related meter P + weather/time` 구조를 쉽게 다룰 수 있다.
- C 방식을 쓰면 모델 수를 줄이면서도 계량기별 샘플 구분을 유지하기 쉽다.
- SHAP 등 해석 도구 적용도 상대적으로 쉽다.

## 현재 추천

### 이상탐지

- STL: 현재처럼 계량기별 핵심 타깃 유지
- IF: 최종 후보는 B 방법(군집별 IF)
- IF: A 방법은 관계형 이상탐지 실험용 후보
- IF: C 방법은 현재 우선순위 낮음
- 이상탐지 LSTM: 당장은 본인 feature 중심 유지

### 예측

- 최종 주력 후보: `Boosting + A + C`
- 예측 LSTM: `A + C` 비교군으로 적절
- B 방법은 가능하지만, C보다 계량기 개성 보존 측면에서 불리할 수 있음

## 한 줄 결론

- 이상탐지 최적안:
  - `STL 개별`
  - `IF 군집별(B)`
  - `이상탐지 LSTM 개별`
- 예측 최적안:
  - `Boosting + A + C`를 최우선
  - `예측 LSTM + A + C`를 비교군으로 운영
- 현재 우선순위:
  1. 예측에 `A + C` 적용
  2. 이상탐지 IF에 `B` 적용
  3. 필요 시 IF의 `A`를 관계형 이상탐지 실험으로 제한 적용

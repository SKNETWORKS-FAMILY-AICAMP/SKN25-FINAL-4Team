## 프로젝트 개요

**GameOps**는 게임 유저 문의 관리 및 맞춤형 응대 자동화 솔루션이다.

> AI가 일반 문의를 자동 처리하고, 고위험 이슈 관리와 운영 인사이트 도출을 지원하는 **다중 에이전트 서빙 기반** 시스템

단순 FAQ 챗봇을 넘어, **문의 수집 → AI 분석 → RAG 응답 생성 → 운영 처리 → 인사이트 제공**까지 하나의 흐름으로 연결한다.

---

## 배경 및 문제 정의

### 현재 게임 CS의 문제

| 문제 | 해결 방향 |
|---|---|
| 반복 문의 처리에 운영자 시간 지속 소요 | 문의 유형 분류 → **단순 문의 AI 즉시 응답** |
| 긴급·일반 문의 혼재로 식별 어려움 | 위험도 판단 → **AI 선별 고위험 문의 우선 검토** |
| 담당자별 답변 기준·표현 방식 상이 | 문서 및 DB 검색 → **FAQ·이용 기록 기반 맞춤 응답 생성** |
| 문의·반응 데이터 활용 한계 | 데이터 파이프라인 구축 → **문의·반응 분석 기반 운영 리포트 자동화** |

---

## 핵심 기능

### 01. 게임 운영 문서 기반 RAG 응답

FAQ, 공지사항, 패치노트, 운영 정책을 검색하여 최신 이벤트·보상 기준·패치 내용을 반영한 답변을 생성한다.

### 02. 챗봇·게시판 문의 통합 처리

챗봇 문의와 네이버 카페 기반 게시판 문의/피드백을 함께 수집하여 자동 응답, 댓글 초안, 운영자 검토 흐름으로 연결한다.

### 03. 고위험 이슈 탐지 및 운영 인사이트

결제 오류, 보상 불만, 계정 문제, 버그 신고 등 민감 이슈를 우선 분리하고, 반복 문의와 유저 반응 흐름을 대시보드로 제공한다.

## 시스템 아키텍처

### 통합 파이프라인

```
1. 데이터 수집          2. AI 분석               3. RAG 응답 생성
챗봇 문의와 공식   →   문의성 글 판별,       →   FAQ·공지·패치노트
카페 게시글 수집        유형 분류, 리스크           기반 답변·댓글
                        탐지 수행                  초안 생성
                                ↓
                4. 운영 처리                 5. 인사이트 제공
           AI 기반 응답 또는          문의 유형, 반복 이슈,
           운영자 검토 대상으로   →   유저 반응 흐름 확인하는
           구분                        운영 대시보드
```

### 챗봇 아키텍처

```
사용자 문의
     │
     ▼
공통 전처리 / 의도 파악 (Query Enrichment · LLM intent)
     │
     ▼
Category Routing (문의 유형 분류 및 라우팅)
     │
     ├── FAQ Agent      ── 문서 기반 답변, 검색·재정렬·근거 응답
     ├── VOC Agent      ── 불만·건의 분류, 운영 인사이트 적재
     ├── 결제 Agent     ── 결제·환불·미지급 확인, 사용자 DB 조회
     └── 버그 Agent     ── 버그·오류 분류, 운영자 전달 판단
                │
                ▼
         응답 초안 저장 (에이전트 응답 임시 저장)
                │
                ▼
         Safety Layer (개인정보·근거성·검토 필요 여부 확인)
         ┌──────────────────────────────────────┐
         ▼                    ▼                  ▼
     자동응답            운영자 검토 알림       캐시 로그 저장
  (승인 완료 시)        (검토 필요 시)        (최종 답변 및
                                              메타데이터)
```

## 멀티 에이전트 구성

| 에이전트 | 역할 |
|---|---|
| **Orchestrator** | 요청 분석 및 적합 에이전트 라우팅 |
| **FAQ Agent** | FAQ·공지·패치노트 기반 응답 생성 |
| **VOC Agent** | 불만·건의·피드백 분류, 운영 인사이트 적재 |
| **Payment Agent** | 결제·환불·미지급 문의 처리, 사용자 DB 조회 |
| **Bug Agent** | 인게임 버그·반복 오류 분석, 운영자 전달 판단 |
| **컨텍스트 수집** | RAG 검색 및 관련 데이터 조회 |

### 챗봇 처리 단계

| 단계 | 내용 |
|---|---|
| 1. 사용자 입력 | 문의 텍스트, 계정 정보, 파일 첨부, 세션 관리, 입력 전처리 |
| 2. AI 에이전트 처리 | Orchestrator → 전문 에이전트 → 컨텍스트 수집 |
| 3. 응답 생성 및 검증 | 답변 초안 생성, 근거 문서 연결, 안전성 검증(Moderation), 응답 보강, 최종 응답 |
| 4. 응답 전달 및 후처리 | 사용자 응답 전달, 운영자 검토 라우팅, 대화 요약 저장, 지식/FAQ 개선, 이슈 자동 분류 |
| 5. 모니터링 및 분석 | 실시간 모니터링, FAQ/VOC/결제/버그 비율 분석, 품질 지표, 운영 리포트, 리스크 감지, 로그 내보내기 |

## 운영 배치 파이프라인

카페 게시글 수집 → 문의성 글 분석 → 자동 댓글 응답 흐름으로 구성된 운영 배치 시스템

```
1. 문의 내용 파악           2. 답변 초안 준비
문의 불러오기          →   근거 찾기 에이전트
문의 종류 분류             근거 내용 정리
관련 기록 모으기           답변 작성 에이전트
처리 방향 판단             긴급 알림 작성
분석 내용 저장             초안·근거 저장
        ↓                          ↓
3. 답변 점검 및 확인        4. 최종 처리 결과
답변 검수 에이전트     →   최종 답변 확정
검수 결과 저장             긴급 알림 전송
사람 검토 보조             처리 상태 반영
재처리 판단 에이전트       운영 화면 표시
수정 반영 에이전트         리포트에 활용
```

**배치 흐름**

```
문의 분류 → 처리 방향 판단 ─일반답변→ 근거 찾기 → 답변 작성 → 답변 검수 ─통과→ 최종 답변 확정
                │                                               │
              긴급 대응                                       위험 감지·추가 확인
                │                                               │
                ▼                                               ▼
          긴급 알림 작성 에이전트 ←─────────────── 사람 검토 보조 에이전트
                                                  (승인 / 반려 / 수정)
```

## 운영자 대시보드

| 화면 | 제공 정보 |
|---|---|
| **전체 흐름 화면** | 오늘 문의 수, 대기 건수, 최근 문의 현황 |
| **위험 신호 화면** | 고위험 문의, 안전 경고, 우선순위 목록 |
| **답변 품질 화면** | 초안 현황, 근거 현황, 실패 내역 |
| **문의 상세 보기** | 이력, 초안, 근거, 안전 점검, 로그 |
| **주간 보고서** | PDF 미리보기, Slack 공유 |

**대시보드 데이터 흐름**

```
정보 입력 (문의 내용, AI 해석 결과, 답변 초안, 안전 점검, 최종 답변, 반복 패턴)
     → 데이터 수집 (최근 N일 범위, 운영 현황, 위험 신호, 답변 품질, 주간 보고)
     → 지표 계산 (운영/위험/품질 지표, 주간 변화, AI 한줄 해석)
     → 화면 표시
```

## SWOT 분석

| | 내용 |
|---|---|
| **Strengths** | 문의·답변 자동화, RAG 기반 정확도 향상, 반복 문의 패턴 분석, 운영 인사이트 도출 |
| **Weaknesses** | 초기 데이터 부족, 운영자 검수 필요, 외부 API 비용 발생 |
| **Opportunities** | 게임 CS 자동화 수요 증가, 운영 효율화 가능, 타 산업 확장 가능 |
| **Threats** | AI 플랫폼 경쟁 심화, 개인정보·규제 리스크, 잘못된 응답 확산 위험 |

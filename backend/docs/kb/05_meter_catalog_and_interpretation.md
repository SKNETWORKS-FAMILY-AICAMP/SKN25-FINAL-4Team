## 미터 데이터 해석 시 자주 하는 질문

### Q: V.Z84의 역률이 -0.94인데 이상인가요?
**A: 정상입니다.** V.Z84는 PV(태양광) 발전 미터입니다. 역률 음수는 전력을 계통으로 역송(공급)하는 발전 상태를 나타냅니다. 소비 설비와 달리 발전 설비는 역률이 음수이거나 낮아야 정상 발전 중임을 의미합니다.

### Q: H1.ZE20과 H1.Z20을 합산해야 하나요?
**A: 절대 합산 금지입니다.** 두 미터는 동일한 CHP 전기 선로를 이중 계측합니다. 합산하면 CHP 발전량이 2배로 과다 계산됩니다. coalesce(ZE20 우선, 없으면 Z20) 방식으로 타임스탬프별 하나만 선택해야 합니다.

### Q: H2.Z35와 H2.Z351을 모두 더해야 하나요?
**A: 합산해도 됩니다 (이중 계산 없음).** H2.Z35는 2020-09-09 이전, H2.Z351은 이후 데이터만 존재합니다. 동일 시점에 두 미터가 동시에 존재하지 않으므로 합산(UNION) 방식으로 전체 그리드 소비량 계산이 안전합니다.

### Q: 야간에 PV 값이 NaN인데 결측인가요?
**A: 정상입니다.** 야간에는 일사량(Igm) = 0이므로 PV 인버터가 절전 모드로 전환되어 계측값을 출력하지 않습니다. NaN = 발전 없음(정상). PVNightNonZero는 야간에 NaN이 아니라 양수값이 측정될 때만 발생합니다.

### Q: grid_P가 음수가 될 수 있나요?
**A: 이론적으로 가능하지만 매우 드뭅니다.** PV + CHP 생산량이 시설 전체 소비량을 초과하면 계통으로 역송(음수)이 발생합니다. Honda R&D 시설은 대부분 소비가 더 크므로 grid_P 음수는 데이터 이상 또는 극히 드문 초과 생산 상황입니다.

## 데이터베이스 스키마 참고

### reference.corrected_resampled_1h (주 데이터 테이블)

```sql
SELECT ts, meter_urn, measurement, value
FROM reference.corrected_resampled_1h
WHERE meter_urn = 'V.Z84'
  AND measurement = 'P'
  AND ts >= '2023-01-01'
ORDER BY ts;
```

주요 컬럼:
- ts: 타임스탬프 (1시간 단위, timezone-aware)
- meter_urn: 미터 URN 식별자 (예: 'V.Z84', 'H1.Z310')
- measurement: 측정 타입 (예: 'P', 'PF1', 'I2', 'Igm', 'Ta')
- value: 측정값 (FLOAT)

### anomaly_results (이상탐지 결과 테이블)

주요 컬럼:
- timestamp: 이상 발생 시각
- anomaly_type: 이상 유형 (PowerSpike/COPDrop/NightConsumption/CHPOutage/PVNightNonZero)
- severity: 심각도 (HIGH/MEDIUM/LOW)
- vote_count: 앙상블 투표 수 (1~3)
- description: 탐지 상세 (vote 정보, stat/iso/lstm 플래그)
- gateway_failure: 게이트웨이 장애 구간 여부 (TRUE면 인공 보정 데이터)

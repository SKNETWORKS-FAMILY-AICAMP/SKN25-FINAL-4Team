# Honda R&D Europe GmbH — 에너지 관리 시스템 시설 개요

## 시설 기본 정보

Honda R&D Europe GmbH는 독일 헤센주 오펜바흐(Offenbach am Main)에 위치한 자동차 연구개발 센터입니다.
전력망은 독일 공공 전력망에 연결되어 있으며, 2017년부터 2024년까지의 에너지 데이터가 수집되었습니다.
시설에는 총 81개의 전기·열·냉방·기상 계측기가 설치되어 있습니다.

## 건물 구역 (6개 구역)

### H1 — 배기가스 시험실 (주요 에너지 소비 구역)
- 용도: 차량 배기가스 시험, HVAC 테스트 설비
- 설치 계측기: 전기 29개, 냉방 4개, 열량 2개
- 태양광: H1.Z310 (PV Phase 1, Phase 2 포함)
- CHP 전기 계측: H1.ZE20 (2023년 이후) / H1.Z20 (2022년 이전)
- 에너지 소비량이 시설 전체에서 가장 큰 구역

### H2 — 워크숍·서버실
- 용도: 자동차 부품 워크숍, CIS/EU 서버실, Robolab (로봇 연구소)
- 설치 계측기: ABB-B24 전기 미터 (H2.T.Z* 계열)
- 태양광: H2.Z311
- 특이사항: 열량 미터 없음. 서버실 연속 가동으로 야간 기저 부하 존재

### H3 — 디자인 스튜디오
- 용도: 자동차 디자인 작업실, 주행 시뮬레이터
- 설치 계측기: 전기 미터만 (열량·냉수 미터 없음)
- 태양광: H3.Z312

### H4 — 사무동 (B4)
- 용도: 일반 사무 공간
- 설치 계측기: 전기 4개 미터만
- 특이사항: 소규모 구역, 에너지 소비량 낮음

### V — 부지 공통 (외부 연결 거점)
- 역할: 외부 계통 전력 변압기(V.Z81, V.Z82), PV 주차장(V.Z84)
- V.Z81·V.Z82: 주차장 변압기 (H1·H2·H3 전력 공급 담당)
- V.Z84: 주차장 상부 태양광 패널 (발전 설비, 역률 음수 = 정상)
- 주의: V.Z81의 W_in(누적 전력량) 컬럼은 오버플로우(-55억 kWh)로 사용 불가

### WeatherStation — 기상 관측소
- 장비: Lufft WS501-UMB 기상 센서
- 측정 항목: 일사량(Igm, W/m²), 외기온(Ta, °C)
- 용도: PV 발전량 예측, COP 보정, 에너지 패턴 분석

## 에너지 공급원 3종

### 외부 계통 전력 (GridConnection)
- 독일 공공 전력망에서 직접 인입
- 주요 미터: V.Z81, V.Z82, H2.Z35/Z36 (구형), H2.Z351/Z361 (신형, 2020-09-15 이후 교체)
- 4개 변압기 전체 합산이 시설 전체 그리드 소비량 (변수명: grid_P)
- 양수 = 소비(인입), 음수 = 역송(발전)

### 태양광 PV (PVSystem)
- 설치 위치: H1·H2·H3·V 지붕 및 주차장
- 총 설비 용량: 749 kWp
- Phase 1 설치: 2019-06-01 / Phase 2 증설: 2020-06-01 (풀 용량 달성)
- 주요 미터: H1.Z310, H2.Z311, H3.Z312, V.Z84 (4개 그룹 합산)
- PV 미터는 음수값 → abs() 처리 후 '발전량'으로 표현 (변수명: pv_P)

### 열병합발전 CHP (CHPSystem)
- 역할: 전기와 열을 동시 생산 (Combined Heat and Power)
- 전기 계측: H1.ZE20 (2023년 교정 의무 설치) / H1.Z20 (2022년 이전 원본)
  ※ ZE20과 Z20은 동일 선로 이중계측 — 합산 금지, coalesce(ZE20 우선) 처리
- 열 계측: H1.W12 (CHP 생산 열), H1.W11 (총 열량)
- 변수명: chp_P (전기), chp_heat_P (열)
- 2019-02-13: CHP Logic 변경 — On/Off 방식에서 연속 모듈레이션 방식으로 전환
- 2023-06-01: Heat Modernization으로 하절기 가동 패턴 변경

## 에너지 시스템 3종

### 전기 시스템 (ElectricalSystem)
- 구성: 계통(grid_P) + PV(pv_P) + CHP(chp_P)
- 단위: W (와트)
- 자급률 = (PV + CHP) / (Grid + PV + CHP)
- 6년 평균 자급률: 39.6% (2022년 최고 46.9%)

### 난방 시스템 (HeatingSystem)
- 구성: CHP 폐열(chp_heat_P), 총 열 공급량(heat_total_P)
- 겨울철 열 수요 증가 시 CHP는 열 생산 우선 → 전기 효율 소폭 감소(±3~5%p)는 정상

### 냉방 시스템 (CoolingSystem)
- 냉방 전기 투입: H1.Z11, H1.Z12, H1.Z16, H1.Z24, H1.Z25 (CM1~3 합산, 변수명: cool_elec_P)
- 냉수 출력: V.K21 (3대 냉각기 합산 주 미터, 변수명: cool_output_P)
- COP = cool_output_P / cool_elec_P (cool_elec=0일 때 계산 불가 — 방어 코드 필수)
- COP 중앙값: 2.06. 여름(외기온 30°C 이상)에는 1.7~2.0도 정상

## 데이터 품질 관련 주의사항

### 게이트웨이 장애 구간 (인공 보정 데이터)
해당 기간의 데이터는 실측값이 아닌 과거 패턴 복사값이므로 이상 판정 금지:
- 2020-02-13 ~ 2020-03-06: Workshop Gateway Failure #1
- 2020-08-20 ~ 2020-09-17: Emission Lab Gateway Failure
- 2021-11-15 ~ 2021-12-10: Distribution Gateway Failure (기상 데이터 10% 결측)
- 2022-05-06 ~ 2022-07-14: Workshop Gateway Failure #2 (69일간)

### 미터 교체 이벤트
- 2020-09-09: H2.Z35/Z36 → H2.Z351/Z361 교체 (6일간 결측 발생)
- 2023년 이후: H1.ZE20이 H1.Z20을 대체 (동일 선로, 합산 금지)

### COVID-19 영향 구간
- 2020-03-01 ~ 2020-06 전후: 가동 패턴 급변 (부하 감소)

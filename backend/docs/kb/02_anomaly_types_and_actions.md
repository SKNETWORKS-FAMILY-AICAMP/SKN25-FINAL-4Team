# Honda R&D Europe GmbH — 이상탐지 유형별 원인 분석 및 조치 가이드

## 이상 유형 개요

EMS(에너지 관리 시스템)는 5가지 이상 유형을 탐지합니다.
앙상블 모델(통계 + Isolation Forest + LSTM AE) 다수결로 신뢰도를 평가합니다.
- HIGH: 3개 모델 모두 탐지
- MEDIUM: 2개 모델 탐지
- LOW: 1개 모델만 탐지 (기록 유지, 즉각 조치 불필요)

---

## 1. PowerSpike — 전력 급등

### 정의
그리드 인입 전력(grid_P)이 정상 범위를 초과하여 급격히 상승하는 현상.
설비 동시 기동, 과부하, 역률 저하 등이 주원인.

### 주요 원인
- **대형 설비 동시 기동**: 냉각기·압축기·환기팬 동시 기동 시 기동 전류(돌입 전류) 급등
- **변압기 과부하**: V.Z81/Z82 변압기 부하 초과
- **역률 저하**: 무효전력 과다로 겉보기 전력(kVA) 증가 → 계통 전력 급증
- **계통 전압 저하**: 전압 강하 시 전류 상승 연쇄

### 판단 기준
- grid_P가 시간대별 정상 범위 대비 30% 이상 초과
- 겨울 피크(난방+조명 동시): 정상 상한 1,200~1,400 kW
- 여름 피크(냉방 피크): 정상 상한 1,000~1,200 kW

### 조치 방법
1. 현장 정비팀: V.Z81·V.Z82 변압기 부하율 및 3상 전류 불평형 확인
2. 운영팀: 동시 기동된 대형 설비(냉각기·압축기) 스케줄 분산 (순차 기동 절차 적용)
3. 전기팀: 역률 개선 콘덴서 정상 동작 여부 및 커패시턴스 측정
4. 경과 관찰: HIGH 등급 반복 발생 시 피크컷 설정값 재검토

### 오판단 주의
- 겨울 아침 07~09시 일괄 기동: 정상 피크 패턴 (이상 아님)
- PV 출력 급감 시 계통 전력 자연 증가: 기상 원인 확인 필요

## 2. COPDrop — 냉방 성능계수(COP) 급락

### 정의
냉방 COP(= cool_output_P / cool_elec_P)가 기준값 이하로 하락.
냉방 효율 저하를 나타내며, 에너지 낭비와 직결.

### COP 해석 기준
- 중앙값: 2.06 (전체 데이터 기준)
- 여름(외기온 30°C 이상): 1.7~2.0도 정상 (물리적 특성)
- 주의 수준: COP < 1.7 (외기온 정상 상황)
- 심각 수준: COP < 1.5 (강제 차단 및 긴급 점검 권고)
- cool_elec_P = 0일 때: COP 계산 불가 (0나누기), 이상 판정 금지

### 주요 원인
- **응축기 코일 열화/오염**: 열 방출 효율 저하 → 냉매 고압 상승 → COP 하락
- **냉각수 스케일 누적**: 배관 내 스케일로 열교환 효율 저하
- **냉매 부족**: 냉매 누설로 압력 저하 → 냉동 사이클 효율 감소
- **냉각탑 고장**: 팬 정지 또는 충진재 막힘으로 응축 온도 상승
- **외기온 급등**: 하절기 35°C 이상에서 물리적 COP 한계 도달

### 하절기 운영 지침
- 6~8월 하절기 무리한 풀 부하 운전 지양
- 주간 전력 피크 타임(10:00~16:00) 출력 80% 이상 모듈레이션 조절
- 계통 전력 피크 컷을 보조하는 방식으로 운영

### 조치 방법
1. 현장팀: 냉각탑 팬 작동 상태 및 충진재 오염 점검
2. 정비팀: 응축기 코일 청소 (고압 세척)
3. 냉방 담당: 냉매 압력 측정 및 냉매 보충 여부 판단
4. 모니터링팀: cool_output_P / cool_elec_P 시계열 추세 연속 관찰
5. 심각(COP < 1.5): 강제 차단 후 긴급 점검

### 계절별 정상 범위
| 외기온 | 정상 COP 범위 |
|--------|--------------|
| < 15°C (겨울) | 2.2 ~ 2.8 |
| 15~25°C (봄·가을) | 1.9 ~ 2.3 |
| 25~30°C (초여름) | 1.7 ~ 2.1 |
| > 30°C (한여름) | 1.5 ~ 1.9 |

## 3. NightConsumption — 야간 이상 소비

### 정의
운영 시간 외(18:00 이후 ~ 07:00, 주말·공휴일)에 비정상적인 전력 소비 감지.
정상 야간 기저 부하(서버실·보안 장비 등)를 초과하는 경우 이상으로 판정.

### 정상 야간 기저 부하 (H2 서버실)
H2 구역 서버실(CIS/EU 서버실)은 24시간 연속 가동 — 야간에도 일정 전력 소비 정상.
NightConsumption 이상 판정 시 H2 서버실 부하 차감 후 평가 필요.

### 주요 원인
- **설비 미차단**: 퇴근 후 HVAC, 조명, 전열 기구 미차단
- **공기압축기 미차단**: 야간·주말 공기압축기 공급 메인 밸브 미차단 (연간 15MWh 이상 낭비 가능)
- **환기 송풍기 과잉 운전**: 야간 환기팬 에코(Eco) 모드 미전환
- **보안 이슈**: 비인가 설비 가동 또는 외부 접근 (드문 경우)
- **배치 공정 무단 운영**: 사전 승인 없는 야간 실험·테스트 가동

### 야간 대기 전력 차단 프로토콜 (표준 절차)
퇴근 시간(18:00) 이후 당직 근무자 점검 항목:
1. 공기압축기 공급 메인 밸브 차단
2. 환기 송풍기 풍량을 최소 에코(Eco) 모드로 전환
3. H1 배기가스 시험실 비가동 장비 전원 차단
4. 불필요 조명 소등 확인

### 조치 방법
1. 관제팀: 야간 분기별 전력 로그 조회 (어느 미터에서 증가했는지 확인)
2. 현장팀: H1·H2·H3 구역 순회 점검 (미차단 설비 차단)
3. 운영팀: 자동 차단 타이머 및 BAS(빌딩 자동화 시스템) 설정 검토
4. 보안팀: 비인가 접근 여부 CCTV 확인 (HIGH 등급 야간 이상)

## 4. CHPOutage — 열병합발전 정지

### 정의
CHP 전기 생산량(chp_P)과 열 생산량(chp_heat_P)이 동시에 0에 가까워지는 상황.
자급률 급감, 그리드 의존도 급등으로 이어짐.

### 판단 기준
- chp_P < 5 kW (전기 생산 정지)
- chp_heat_P < 10 kW (열 생산 정지)
- 두 조건 동시 만족 시 CHPOutage

### 주요 원인
- **연료(가스) 공급 차단**: 가스 공급 밸브 고장 또는 공급사 문제
- **계획 정비 셧다운**: 정기 점검·부품 교체 (일정 공유 필수)
- **과열 보호 트립**: 냉각 시스템 이상으로 과열 → 안전 차단
- **전자제어 장치 오류**: PLC·인버터 오류로 운전 불가
- **Heat Modernization(2023-06)**: 하절기 가동 패턴 변경 후 정지 빈도 증가 가능

### CHP 운전 모드 변화 이력
- 2019-02-13 이전: On/Off 방식 (켜짐/꺼짐 이진 제어)
- 2019-02-13 이후: 연속 모듈레이션 방식 (출력을 연속적으로 조절)
- 모듈레이션 전환 후 CHPOutage 빈도 감소, 부분 출력 상태 증가

### 조치 방법
1. 운영팀: chp_P + chp_heat_P 동시 0 확인 (또는 5 kW 이하)
2. 현장팀: 가스 공급 메인 밸브 및 가스 압력 게이지 확인
3. 정비팀: CHP 제어 패널(PLC) 알람 코드 확인 및 재시작 시도
4. 모니터링팀: 그리드 의존도 급등 여부 지속 관찰 (CHPOutage → grid_P 증가)
5. 계획 정비인 경우: EMS에 정비 일정 입력하여 이상 알람 억제

## 5. PVNightNonZero — 태양광 야간 비정상 출력

### 정의
야간(22:00~06:00) 태양광 발전량(pv_P)이 500W 이상의 양수 값으로 계측되는 현상.
정상적인 야간은 일사량(Igm) = 0이므로 PV 출력은 0 또는 NaN이어야 함.

### 정상 야간 PV와의 구별
- 정상: 야간 PV = NaN (센서 절전 모드, 출력 없음)
- 이상: 야간 PV > 0 W (센서 오류 또는 인버터 오프셋)
- 새벽(04:00~06:00) 일출 직전 미세 값: 정상 범위 (계절·위도 고려)

### 주요 원인
- **인버터 오프셋 오류**: 인버터 내부 보정값 오류로 야간에도 작은 양수값 출력
- **센서 오결선**: 계측기 배선 오류로 오신호 전송
- **인버터 절전 제어 릴레이 고장**: 절전 차단이 되지 않아 잡음 신호 유입
- **EMI 간섭**: 주변 전자기기 간섭으로 계측값 왜곡

### 역률 해석 주의
V.Z84(PV 주차장) 역률이 음수(-0.9 등)로 나타나는 경우:
→ 전력을 계통으로 역송(발전) 중인 정상 상태 (이상 아님)
→ 발전 설비(PV·CHP)는 역률 음수가 정상 운전 상태임

### 조치 방법
1. 정비팀: 해당 인버터 룸 제어 릴레이 접점 검사
2. 계측팀: 인버터 절전 차단 설정값 확인 및 재설정
3. 1주일 이상 현상 지속: 센서 캘리브레이션 요청 및 갱신
4. 즉각적 운전 영향 없음 (LOW 우선순위) — 경과 관찰 허용

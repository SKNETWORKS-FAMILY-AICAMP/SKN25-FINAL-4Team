# Honda R&D Europe GmbH — KPI 공식, 단위, 해석 기준

## 핵심 KPI 공식

### 1. 자급률 (Self-Sufficiency Rate)

```
자급률(%) = (PV 발전량 + CHP 발전량) / (계통 전력 + PV 발전량 + CHP 발전량) × 100
```

- 변수명: self_sufficiency (소수점) 또는 self_sufficiency_pct (퍼센트)
- 단위: % (0~100)
- **6년 평균 기준값: 39.6%**
- 연간 최고: 2022년 46.9% (PV Phase 2 풀 가동 + CHP 정상 운영)
- 의미: 값이 높을수록 외부 전력 의존도 낮음 = 에너지 자립도 높음

### 2. 그리드 의존도 (Grid Dependency)

```
그리드 의존도(%) = 계통 전력 / (계통 전력 + PV + CHP) × 100
```

- 자급률의 반대 개념: 그리드 의존도 + 자급률 ≈ 100%
- (두 값 합이 100%에서 크게 벗어나면 데이터 품질 문제 의심)
- **기준값: 60.4%** (자급률 39.6%의 보완값)

### 3. 성능계수 COP (Coefficient of Performance)

```
COP = 냉방 출력(cool_output_P) / 냉방 전기 투입(cool_elec_P)
```

- 단위: 무차원 (에너지 효율 비율)
- **중앙값 기준: 2.06**
- cool_elec_P = 0 일 때: COP 계산 불가 (0나누기), NaN 처리 필수
- 의미: COP가 높을수록 냉방 효율 좋음 (투입 전기 대비 더 많은 냉방 효과)

### 4. 에너지 밸런스 검증

```
총 소비 ≈ 계통 인입 + PV 생산 + CHP 생산
자급률 + 그리드 의존도 ≈ 100%
```

- 밸런스 오차 5% 초과 시 데이터 품질 경고
- 게이트웨이 장애 구간에서 밸런스 불일치 빈번

## 에너지 단위 체계

### kW vs kWh — 혼용 금지

| 단위 | 의미 | 사용 예시 |
|------|------|---------|
| **kW** | 순간 전력 (Power) | "현재 냉각기가 350 kW를 소비 중" |
| **kWh** | 에너지 소비량 (Energy) | "이번 달 총 소비량 45,000 kWh" |
| **A** | 전류 (Current) | 전기 안전, 케이블 용량 계산 |
| **V** | 전압 (Voltage) | 3상 전압 불평형 분석 |
| **W/m²** | 일사량 (Irradiance) | 태양광 발전량 예측 |
| **°C** | 외기온 (Temperature) | 냉방 부하, COP 보정 |

**주의**: "kWh당 비용"이 아니라 "kWh 단가"로 표현. kW와 kWh는 절대 혼용 금지.

### 측정 해상도 및 스키마

- **1시간 단위**: `reference.corrected_resampled_1h` 테이블 (주 데이터)
- **15분 단위**: `reference.corrected_resampled_15min` 테이블 (고해상도)
- 데이터 기간: 2017년 ~ 2024년 1월 1일

## 역률(Power Factor) 해석

### 소비 설비 vs. 발전 설비 역률 판단 기준

| 설비 유형 | 정상 역률 범위 | 이상 기준 |
|----------|--------------|---------|
| 소비 설비 (계통·냉방) | 0.85 이상 | 0.85 미만 = 무효전력 과다 |
| 발전 설비 (PV·CHP) | 음수 또는 낮은 양수 | 음수 = 전력 역송(발전) = 정상 |

### 발전 설비 역률이 음수인 이유
- PV 인버터와 CHP 발전기는 전력을 계통으로 역송(공급)
- 역송 상태에서 역률 기준이 소비 설비와 반대로 정의됨
- V.Z84(PV), H1.ZE20(CHP): 역률 -0.9대 = 전형적 역송 정상 상태
- **오판단 금지**: 발전 설비의 음수 역률을 "역률 불량"으로 보고하지 말 것

## 자급률 계절별 정상 범위

### 계절 패턴 이해

자급률은 계절에 따라 크게 변동합니다 — 낮다고 무조건 이상 아님:

| 계절 | 일반 자급률 범위 | 주요 원인 |
|------|----------------|---------|
| 봄·여름 | 45~60% | PV 발전량 최대 (일조량 풍부) |
| 가을 | 30~45% | 일조량 감소, 냉방 부하 감소 |
| 겨울 | 20~35% | 일조량 최저, 열 수요 증가로 CHP 부하 이동 |
| 게이트웨이 장애 구간 | 데이터 신뢰 불가 | 인공 보정 데이터 |

### COVID-19 영향 (2020년 3월~6월)
- 연구소 운영 축소로 전체 부하 감소
- 자급률 상승, CHP 출력 감소
- 해당 기간 이상 판정 시 코로나 영향 고려 필수

## 월별 KPI 리포트 해석 기준

### monthly_report 테이블 주요 컬럼

| 컬럼명 | 의미 | 단위 |
|--------|------|------|

- 자급률 YoY 변화: PV 증설, CHP 효율 개선 효과 확인

## 이상탐지 앙상블 모델 신뢰도 기준

### vote_count 의미

| vote_count | 의미 | severity | 권고 조치 |
|-----------|------|----------|---------|
| 3 | 3개 모델 모두 탐지 | HIGH | 즉각 점검 필요 |
| 2 | 2개 모델 탐지 | MEDIUM | 주의 관찰, 반복 시 점검 |
| 1 | 1개 모델만 탐지 | LOW | 기록 유지, 경과 관찰 |

### 각 모델 특성

- **통계 모델(stat)**: Z-score 기반. 극단값에 민감. 급격한 스파이크에 강함.
- **Isolation Forest(iso)**: 비지도 학습. 다변수 패턴 이상 감지. 이상 클러스터 탐지.
- **LSTM AE(lstm)**: 딥러닝 시계열 재구성 오차. 패턴 변화(regime change) 민감.

LOW 등급은 LSTM만 탐지하는 경우가 많음 — 게이트웨이 장애 구간 주의.

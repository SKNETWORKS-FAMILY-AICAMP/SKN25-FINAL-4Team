EMS 예측 target 정책 및 A 계열 확장 전략

전력 수요 예측 target을 A/B/C/D 등급으로 분리하고, A 계열에서 champion recipe를 선정한 뒤 grid demand와 versioned target으로 확장하는 기준을 정리한다.

현재 target 범위

현재 target catalog는 electricity / consumption / P 범위로 제한되어 있다. production, thermal, weather는 demand target에서 제외한다.
전기 소비 P redundant endpoint 제외 PV/CHP target 제외 thermal/heating target 제외 weather target 제외

냉방 관련 target인 central_cooling_P, local_cooling_P는 냉방 설비의 전기 소비 P이며, 냉방 열량 target과는 구분한다.

A 계열 benchmark

A 계열은 champion model 자체보다 champion recipe를 선정하는 기준 집합이다. recipe는 모델 구조, sequence length, feature set, missing-data policy, scaler policy, outage policy, loss, early stopping 규칙을 포함한다.

확장 순서

  1. A 계열에서 champion recipe를 선정한다.
  2. grid_transformer_P는 grid_demand 실험군으로 별도 확장한다. H2 transformer replacement gap 142시간은 exclude 또는 flag 처리한다.
  3. H2, H3, design studio, workshop target은 version별 target 의미를 문서화한 뒤 확장 실험한다.
  4. H4, office distribution은 2023-06-23 이전 중심의 period-limited target으로 실험한다.
  5. all consumption은 aggregate 검산과 coverage drift 진단에 우선 사용한다.

진행 판단

A 계열부터 본격적으로 들어가는 방향은 타당하다. 다만 바로 LSTM 재학습으로 들어가기보다 target 정책 산출물 확정, A 계열 target dataset builder, naive baseline을 먼저 통과한 뒤 LSTM 또는 개선 모델을 적용하는 순서가 안전하다.

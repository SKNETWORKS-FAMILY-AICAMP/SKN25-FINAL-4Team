# 중간발표 고품질 PPT 시안

최신 slide_script.md 기준으로 1~3쪽만 다시 제작했습니다.

## 포함 파일

- fems_premium_3slides_visual_checked.pptx: 브라우저 렌더링으로 검수한 이미지를 전체 슬라이드로 삽입한 PPTX
- fems_premium_3slides.html: 원본 디자인 HTML
- rendered/slide_01.png ~ slide_03.png: 실제 렌더링 이미지
- rendered/contact_sheet.png: 전체 미리보기

## 검수 내용

- 크롬 헤드리스로 1920×1080 실제 렌더링
- 3쪽 제목/본문 겹침 수정
- 3쪽 중앙 카드의 한글 줄바꿈 오류 수정
- PPTX 내부 파일 구조 검증

## 주의

PPTX는 검수된 화면을 그대로 보존하기 위해 슬라이드별 이미지를 삽입한 버전입니다. 텍스트 직접 편집이 필요하면 HTML 원본을 수정한 뒤 다시 내보내는 방식이 안정적입니다.

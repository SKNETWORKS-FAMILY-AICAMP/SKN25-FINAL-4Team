# 중간발표 디자인 시안

최신 slide_script.md를 기준으로 1~3쪽만 제작한 디자인 시안입니다.

## 파일

1. 01_industrial_control_dark.pptx — 산업 관제 다크
2. 02_executive_light_grid.pptx — 경영진 라이트 그리드
3. 03_thermal_report_warm.pptx — 열지도 리포트 웜
4. 04_blueprint_technical.pptx — 블루프린트 테크니컬
5. 05_mono_precision.pptx — 모노 프리시전
6. all_5_design_options_preview.pptx — 다섯 시안을 한 파일에서 빠르게 비교

## 반영 범위

- 1쪽 표지: 공장/산업시설, 에너지 데이터 흐름, EMS/FEMS/AI 키워드
- 2쪽 목차: 필요성 → 개요 → 데이터 → EDA → 모델링/FEMS → 진행현황 → 목표 흐름
- 3쪽 프로젝트 필요성: CBAM, K-ETS, 탄소중립, 에너지 비용 압력과 EMS 데이터 활용 파이프라인

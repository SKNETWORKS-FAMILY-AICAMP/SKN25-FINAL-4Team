# Huang et al. 2022 기반 EMS A-clean 벤치마크 산출물 인덱스

## 읽는 순서

1. `report.html` — 브리핑용 HTML 문서
2. `report_plotly.html` — Plotly 인터랙티브 문서
3. `report.md` — 동일 내용을 담은 Markdown 문서
4. `tables/prediction_period_summary_ko.csv` — 2018–2023 예측 기간 확인표
- `tables/prediction_plot_scope_ko.csv` — 그래프 표시 범위 설명
5. `tables/model_candidate_setup_ko.csv` — 모델별 하이퍼파라미터와 입력 설정
6. `tables/feature_input_policy_ko.csv` — 입력 피처 구성과 제외 피처
7. `tables/huang2022_all_candidate_results_ko.csv` — 36개 모델 전체 지표
8. `tables/target_policy_explanation_ko.csv` — target policy 설명 표
9. `figures/` — 재생성한 이미지

## 기준

- 2018–2021년 학습, 2022년 모델 검토, 2023년 평가 구조로 설명한다.
- 연도별 예측 패널을 포함한다.
- 하이퍼파라미터와 입력 피처 구성은 본문 표에 유지한다.
